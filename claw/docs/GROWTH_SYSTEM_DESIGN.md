# StarClaw 龙虾养成系统 — 产品设计文档

> 1 主龙虾 + N 虫群 · 星尘经济 · 虫群对战

## 一、核心理念

每个 Claw 节点就是一只龙虾。你用 Claw 越多，龙虾越强。
你创建的每个 Agent 就是虫群里的一只虫。Agent 越多越活跃，虫群越强大。

```
你 ── Claw 节点 ── 主龙虾（虫后）
                      │
          ┌───────────┼───────────┐
          ▼           ▼           ▼
      Agent A      Agent B      Agent C
      量化分析虫    创意虫       社交虫
      (麒博)       (视频创作)    (微信客服)
```

**设计哲学：用户为了让虫群更强，会自然地创建更多 Agent、使用更多功能 —— 增长飞轮自转。**

## 二、角色体系

### 2.1 主龙虾（虫后）

每个 Claw 节点唯一拥有的核心角色。

| 属性 | 来源 | 说明 |
|------|------|------|
| **等级** | 所有 Agent 的使用量累加 | Lv.1 → Lv.50，决定进化形态 |
| **HP** | 记忆数量 | 越多记忆，生命值越高 |
| **ATK** | 完成任务数 | 越多任务，攻击力越高 |
| **DEF** | 用户好评数 | 越多好评，防御力越高 |
| **SPD** | 对话次数 | 越多对话，速度越高 |
| **EXP** | 所有行为累加 | 升级经验值 |

**进化路线（三选一，Lv.5 时选择）：**

| 路线 | 特点 | 适合 |
|------|------|------|
| 🌊 深渊之路 | HP/DEF 成长快 | 知识库/RAG 重度用户 |
| 🏔️ 陆地之路 | ATK/SPD 均衡 | 任务/工具重度用户 |
| 🌪️ 天空之路 | SPD/ATK 成长快 | 对话/创意重度用户 |

**进化阶段（以陆地之路为例）：**

```
Lv.1  跳虫 (Zergling)      → 初始形态
Lv.5  刺蛇 (Hydralisk)     → 首次进化，选择路线
Lv.10 潜伏者 (Lurker)      → 解锁虫群指挥能力
Lv.20 雷兽 (Ultralisk)     → 解锁星尘炼金
Lv.30 泰坦 (Titan)         → 解锁变异系统
Lv.50 陆皇 (Colossus)      → 终极形态
```

### 2.2 虫群（Agent 化身）

用户创建的每个 Agent 自动获得一只虫的化身。

| 虫的属性 | 来源 | 说明 |
|---------|------|------|
| **名称** | Agent 名称 | 如"麒博"、"视频创作师" |
| **类型** | 自动判断 | 根据 Agent 的工具/用途分类 |
| **等级** | 该 Agent 的独立使用量 | 每只虫有独立等级 |
| **专项能力** | 该 Agent 的核心能力 | 量化分析/视频创作/代码编写... |
| **战斗技能** | 解锁于虫等级 | 每只虫有 1-3 个独特技能 |

**虫的类型自动分类：**

| 类型 | 图标 | 判断条件 | 战斗特长 |
|------|------|---------|---------|
| 🏦 财务官虫 | 金色 | 有 trading 工具 | 经济压制（偷星尘） |
| 🎬 创意虫 | 紫色 | 有 video/image/music 工具 | 灵感爆发（随机暴击） |
| 💬 社交虫 | 蓝色 | 有 wechat/telegram 等通讯工具 | 外交斡旋（降低攻击） |
| 💻 工程虫 | 绿色 | 有 code/git 工具 | 代码壁垒（增加防御） |
| 🔍 侦察虫 | 黄色 | 有 web_search/browser 工具 | 情报搜集（先手攻击） |
| 🧠 学者虫 | 青色 | 有 RAG 知识库 | 知识护盾（减伤） |
| ⚔️ 通用虫 | 灰色 | 无特殊工具 | 基础攻击 |

### 2.3 虫群总战力

```
虫群总战力 = 主龙虾属性 + Σ(每只虫的属性 × 星尘加成)

具体计算：
  总 HP  = 主龙虾 HP  + 虫1 HP × 0.3 + 虫2 HP × 0.3 + ...
  总 ATK = 主龙虾 ATK + 虫1 ATK × 0.3 + 虫2 ATK × 0.3 + ...
  ...

  虫的贡献 = 30% 的独立属性（避免堆数量碾压）
  但虫的数量有加成：每多一只虫，全体属性 +2%
```

## 三、星尘经济

### 3.1 星尘获取

| 行为 | 星尘奖励 | 频率限制 |
|------|---------|---------|
| 每日登录 | +5 | 每日 1 次 |
| 完成一次对话 | +1 | 每日上限 50 |
| Agent 完成任务 | +3 | 每日上限 30 |
| 创建新 Agent | +20 | 一次性 |
| Agent 获得好评 | +5 | 无限制 |
| 连续使用 N 天 | +N×2 | 每日结算 |
| 竞技场胜利 | +10~30 | 无限制 |
| 里程碑达成 | +50~200 | 一次性 |

### 3.2 星尘分配

用户可以自由决定星尘的用途：

```
星尘商店
├── 🦞 主龙虾强化
│   ├── HP +10 (消耗 50 星尘)
│   ├── ATK +5 (消耗 40 星尘)
│   ├── DEF +5 (消耗 40 星尘)
│   └── SPD +5 (消耗 40 星尘)
│
├── 🐛 虫群强化
│   ├── 给指定虫加属性 (消耗 30 星尘/点)
│   ├── 解锁虫的隐藏技能 (消耗 200 星尘)
│   └── 虫的外观皮肤 (消耗 100 星尘)
│
├── 🥚 孵化新虫
│   ├── 普通孵化 (消耗 100 星尘, 随机类型)
│   ├── 定向孵化 (消耗 300 星尘, 选择类型)
│   └── 变异孵化 (消耗 500 星尘, 特殊能力)
│
├── ⚔️ 竞技场装备
│   ├── 武器 (增加 ATK)
│   ├── 护甲 (增加 DEF)
│   └── 饰品 (增加 SPD 或特殊效果)
│
└── 🎨 外观
    ├── 主龙虾皮肤
    └── 称号
```

### 3.3 策略性

**关键设计：星尘是有限的，用户必须做选择。**

- 全投主龙虾 → 个体很强但虫群弱
- 全投虫群 → 虫群很强但主龙虾弱
- 均匀分配 → 中庸但没有短板
- 攒星尘孵化 → 短期弱但长期虫多

**这就是策略深度。每个用户的龙虾+虫群组合都不一样。**

## 四、竞技场：虫群对战

### 4.1 从 1v1 升级到虫群战

```
当前（v1）:
  你的龙虾 vs 对手的龙虾 → 1v1 属性比拼

未来（v2）:
  回合制虫群对战

  第 1 回合: 主龙虾对决（HP/ATK/DEF/SPD 比拼）
  第 2 回合: 虫群出击
    ├── 你选 3 只虫上场
    ├── 对手选 3 只虫上场
    ├── 按 SPD 决定出手顺序
    ├── 每只虫使用自己的技能
    └── 一方虫群全灭 = 该回合失败
  第 3 回合: 如果平局，主龙虾再战

  胜利条件: 3 回合中赢 2 回合
```

### 4.2 虫群技能示例

| 虫类型 | 技能 1 | 技能 2 | 技能 3 (Lv.10 解锁) |
|-------|-------|-------|---------|
| 🏦 财务官虫 | 经济压制：偷对方 5 星尘 | 量化分析：下回合 ATK+20% | 市场操纵：对方全体 SPD-10% |
| 🎬 创意虫 | 灵感爆发：30% 暴击率 | 情绪渲染：己方全体 ATK+10% | 病毒传播：伤害扩散到相邻虫 |
| 💬 社交虫 | 外交斡旋：对方 ATK-15% | 治愈之词：己方一只虫回复 30% HP | 舆论风暴：对方全体 DEF-10% |
| 💻 工程虫 | 代码壁垒：己方 DEF+20% | 自动修复：每回合回复 10% HP | 系统重构：重置对方全部 buff |
| 🔍 侦察虫 | 先手打击：永远第一个出手 | 弱点扫描：下次攻击无视 DEF | 情报网络：揭示对方阵容 |
| 🧠 学者虫 | 知识护盾：抵挡一次攻击 | 经验共享：己方全体 EXP+10% | 真理之眼：对方技能无效化 |

### 4.3 赛季系统

```
每个月一个赛季，3 个环境轮换：
  🌊 深渊赛季 → 深渊路线龙虾 ATK+20%
  🏔️ 大地赛季 → 陆地路线龙虾 DEF+20%
  🌪️ 穹天赛季 → 天空路线龙虾 SPD+20%

赛季奖励：
  前 10% → 限定皮肤 + 500 星尘
  前 30% → 300 星尘
  参与奖 → 50 星尘
```

## 六、技术实现

### 6.1 数据模型变更

```sql
-- 现有表：node_growths (主龙虾，不变)

-- 新增：虫群表
CREATE TABLE swarm_units (
  id          VARCHAR(36) PRIMARY KEY,
  node_id     VARCHAR(64) NOT NULL,     -- Claw 节点 ID
  agent_id    VARCHAR(36) NOT NULL,     -- 对应的 Agent ID
  agent_name  VARCHAR(200),
  unit_type   VARCHAR(20),              -- financial/creative/social/engineer/scout/scholar/generic
  level       INT DEFAULT 1,
  exp         INT DEFAULT 0,
  hp          INT DEFAULT 10,
  atk         INT DEFAULT 10,
  def         INT DEFAULT 5,
  spd         INT DEFAULT 10,
  skill_1     VARCHAR(100),
  skill_2     VARCHAR(100),
  skill_3     VARCHAR(100),             -- Lv.10 解锁
  stardust_invested INT DEFAULT 0,      -- 已投入的星尘
  skin        VARCHAR(50),
  created_at  DATETIME,
  updated_at  DATETIME
);

-- 新增：星尘账户
CREATE TABLE stardust_accounts (
  id          VARCHAR(36) PRIMARY KEY,
  node_id     VARCHAR(64) UNIQUE NOT NULL,
  balance     INT DEFAULT 0,
  total_earned INT DEFAULT 0,
  total_spent  INT DEFAULT 0,
  created_at  DATETIME
);

-- 新增：星尘交易记录
CREATE TABLE stardust_transactions (
  id          VARCHAR(36) PRIMARY KEY,
  node_id     VARCHAR(64) NOT NULL,
  amount      INT NOT NULL,             -- 正数=获得，负数=消耗
  type        VARCHAR(20),              -- earn_daily/earn_chat/earn_task/spend_enhance/spend_hatch/...
  target_id   VARCHAR(36),              -- 目标（主龙虾 ID 或虫 ID）
  note        VARCHAR(200),
  created_at  DATETIME
);

-- 新增：虫群对战记录（扩展现有 arena_battles）
ALTER TABLE arena_battles ADD COLUMN
  attacker_units JSON,                  -- 出战虫 ID 列表
  defender_units JSON,                  -- 出战虫 ID 列表
  battle_log    JSON;                   -- 每回合详细日志
```

### 6.2 API 新增

```
GET  /v1/swarm                  → 获取虫群列表
GET  /v1/swarm/:id              → 获取单只虫详情
POST /v1/swarm/:id/invest       → 给虫分配星尘
GET  /v1/stardust               → 星尘余额
GET  /v1/stardust/transactions  → 星尘交易记录
POST /v1/stardust/enhance       → 星尘强化（主龙虾或虫）
POST /v1/stardust/hatch         → 星尘孵化新虫
POST /v1/arena/challenge        → 虫群对战（扩展）
```

### 6.3 自动化

```
Agent 创建时 → 自动生成对应的 swarm_unit（判断类型）
Agent 使用时 → 自动更新该虫的 EXP
Agent 删除时 → 虫标记为"离群"（不删除，保留属性）
每日结算时 → 计算星尘奖励，更新主龙虾属性
```

## 九、总结

```
核心公式：
  使用 Claw → 龙虾成长 + 虫群壮大 → 竞技场更强 → 获得更多星尘 → 投资虫群 → 想要更多 Agent → 使用更多 Claw

这是一个完美的增长飞轮：
  1. 用户为了龙虾变强 → 使用更多 Claw 功能
  2. 用户为了虫群更多 → 创建更多 Agent
  3. 用户为了竞技场赢 → 投入更多时间
  4. 用户为了限定皮肤 → 付费
  5. 付费不影响平衡 → 免费用户也满足
```

**一句话总结：让每个 Claw 用户都成为虫族女王，指挥自己的龙虾虫群征服 AI 世界。**
