# StarClaw 客户成功手册

> 内部文件 — 确保客户持续使用、续费和增购

---

## 一、客户成功的核心指标

| 指标 | 目标 | 为什么重要 |
|------|:----:|---------|
| **续费率** | ≥ 80% | 续费 = 收入基本盘 |
| **NPS** | ≥ 40 | 高 NPS = 转介绍来源 |
| **活跃率** | ≥ 60% 节点周活 | 不活跃 = 即将流失 |
| **增购率** | ≥ 20% 客户年增购 | 增购 = 收入增长引擎 |
| **平均响应时间** | ≤ 4 小时 | 响应慢 = 满意度下降 |

---

## 二、客户生命周期管理

```
签约 → 交付 → 激活 → 活跃 → 续费 → 增购 → 转介绍
 D0    D1-D14  D15-D30  持续    到期前60天   持续      持续

关键时刻：
  D14  上线激活 — 确保客户真正开始用
  D30  首月回访 — 收集反馈，解决问题
  D90  季度回访 — 评估健康度，推增购
  到期前 60 天 — 启动续费流程
```

---

## 三、客户健康评分

### 3.1 评分模型（满分 100）

| 维度 | 权重 | 满分条件 | 数据来源 |
|------|:----:|---------|---------|
| **活跃度** | 30 分 | ≥60% 节点周活 | Overlord 用量数据 |
| **使用深度** | 25 分 | 用了对话+知识库+Agent 3 项以上 | 功能使用统计 |
| **支持工单** | 15 分 | 过去 30 天无未解决工单 | 工单系统 |
| **账单健康** | 15 分 | 按时付款，无欠款 | 结算系统 |
| **关系温度** | 15 分 | 30 天内有过沟通 | CRM 记录 |

### 3.2 健康等级

| 等级 | 分数 | 状态 | 动作 |
|------|:----:|------|------|
| 🟢 健康 | 80-100 | 活跃使用，正常付费 | 季度回访，推增购 |
| 🟡 关注 | 60-79 | 使用下降或有未解决问题 | 2 周内联系，了解原因 |
| 🔴 风险 | 40-59 | 明显不活跃或有投诉 | 48 小时内联系，制定挽留方案 |
| ⚫ 流失预警 | < 40 | 几乎不用或拒绝沟通 | 升级至核心合伙人/平台处理 |

## 四、关键时刻 SOP

### 4.1 D14 上线激活

**目标：确保客户从"部署完成"变成"真正在用"。**

| 检查项 | 标准 | 未达标怎么办 |
|--------|------|------------|
| 管理员已登录 | 上线后 3 天内 | 电话提醒，必要时远程协助 |
| ≥10% 节点已被使用 | 上线后 7 天内 | 帮客户发内部推广通知 |
| 至少 1 个知识库已创建 | 上线后 14 天内 | 远程帮客户上传示例文档 |

**激活助推话术：**
```
"X 总，系统上线一周了，我看到研发团队已经开始用了。
市场部和 HR 还没登录，建议您发个内部通知推一下。
我可以帮您准备一份员工快速入门指南，您发到群里就行。"
```

### 4.2 D30 首月回访（15 分钟）

| 话题 | 目的 |
|------|------|
| 使用数据回顾 | "上个月贵司 XX 人使用了 AI，研发部用量最大" |
| 满意度 | "目前有没有什么不好用的地方？" |
| 价值确认 | "您觉得 AI 平台对团队效率有帮助吗？" |
| 增购试探 | "有没有其他部门也想用？节点够不够？" |
| 转介绍 | "您身边有朋友的公司也有类似需求吗？" |

### 4.3 D90 季度回访（30 分钟）

| 话题 | 目的 |
|------|------|
| 季度用量报告 | 出具正式报告（PDF），展示 ROI |
| 新功能介绍 | 上季度发布的新功能，建议客户试用 |
| 痛点收集 | 记录客户需求，反馈产品团队 |
| 增购方案 | 根据用量增长推荐升级套餐 |

### 4.4 续费流程（到期前 60 天启动）

```
D-60  发送续费提醒邮件 + 微信通知
D-45  电话沟通续费意向，了解顾虑
D-30  发送续费合同（推年付锁价）
D-14  未签约客户 → 核心合伙人介入
D-7   最终确认，逾期未续 → 降级为 Community
D0    到期
D+7   未续费 → 数据保留 30 天，之后归档
```

**续费话术：**
```
"X 总，贵司的 Pro 版服务将在 60 天后到期。
过去一年贵司共有 XX 人使用了 AI 平台，累计处理了 XX 万次对话。

续费年付的话是 ¥1,599/月，比月付省 ¥4,800。
而且今年续费可以锁定当前价格，明年如果调价也不影响您。"
```

## 五、常见流失原因与挽留方案

| 流失原因 | 信号 | 挽留方案 |
|---------|------|---------|
| **没人用** | 活跃率 < 20% | 免费上门培训 + 帮建 3 个实用 Agent 模板 |
| **觉得贵** | 到期前犹豫 | 展示 ROI 数据；推年付优惠；降级到 Starter 而非流失 |
| **功能不够** | 多次提需求未满足 | 记录需求优先级，承诺排期；提供定制开发报价 |
| **换了竞品** | 突然要求导出数据 | 了解竞品方案，做对比分析；提供迁移成本警示 |
| **公司变动** | 对接人离职/部门调整 | 重新建立关系，联系新对接人 |
| **技术问题** | 频繁工单/投诉 | 升级技术支持，安排专人跟进修复 |

**铁律：降级优于流失。** 客户觉得 Pro 贵 → 推 Starter ¥499/月；Starter 也贵 → 推 Community 免费。留住客户比什么都重要。

## 六、增购机会识别

| 信号 | 增购方向 | 话术 |
|------|---------|------|
| 节点用量接近上限 | 升级套餐 | "贵司节点已用到 85%，建议升级到 Enterprise 避免受限" |
| 新部门开始试用 | 增加节点包 | "看到法务部也开始用了，要不要加 20 个节点？" |
| 客户问白牌 | 推 White-Label | "您想用自己的品牌面向客户？我们有白牌方案" |
| 客户问定制开发 | 增值服务 | "可以的，我们提供定制开发，按人天报价" |
| 客户推荐朋友 | 转介绍 | 感谢 + 赠送 1 个月免费 |
