# StarClaw 市场进入策略（GTM Plan）

> 内部文件 — 从 0 到 100 个客户的落地执行计划

---

## 一、总体策略

```
开源获客（漏斗顶部）→ 社区培育 → 企业试用 → 渠道签约 → 规模化复制

Phase 1 种子期（0-6 月）：创始人 + 3 核心合伙人，验证 PMF，签 10 个客户
Phase 2 增长期（6-12 月）：20 城市合伙人，跑通渠道模型，签 100 个客户
Phase 3 规模化（12-24 月）：100 城市合伙人，30 城市覆盖，签 500 个客户
```

---

## 二、Phase 1 种子期（第 1-6 月）— 验证 PMF

### 目标

| 指标 | 目标值 |
|------|:------:|
| 付费企业客户 | **10 家** |
| GitHub Stars | **2,000** |
| MRR | **¥20,000** |
| 核心合伙人 | **3 人** |
| 城市合伙人 | **5 人** |

### 2.1 先打哪个城市

| 优先级 | 城市 | 理由 |
|:------:|------|------|
| ⭐⭐⭐ | **创始人所在城市** | 零成本人脉触达，快速验证 |
| ⭐⭐ | **杭州** | AI 创业氛围好，中小企业密集 |
| ⭐⭐ | **深圳** | 制造业 + 跨境电商密集，IT 预算高 |

> 第一阶段只打 1-3 个城市，不铺开。每个城市至少签 3 家客户验证可复制性。

### 2.2 先打哪个行业

| 优先级 | 行业 | 首签目标 | 切入方式 |
|:------:|------|:--------:|---------|
| ⭐⭐⭐ | **制造业** | 3 家 | 工厂老板/IT 主管人脉，强调数据安全 |
| ⭐⭐⭐ | **教育** | 3 家 | 学校 IT 部门，强调 AI 教学辅助 |
| ⭐⭐ | **法律** | 2 家 | 律所合伙人，强调合同审查效率 |
| ⭐ | **电商** | 2 家 | 电商运营群，强调文案批量生成 |

### 2.3 第一批 10 个客户怎么来

| 来源 | 方法 | 预计数量 |
|------|------|:--------:|
| **创始人人脉** | 直接联系认识的企业主/CTO | 3-5 家 |
| **核心合伙人人脉** | 核心合伙人自带客户资源 | 2-3 家 |
| **开源社区转化** | GitHub 用户中筛选企业用户 | 1-2 家 |
| **行业活动** | 本地 AI/IT 活动现场签约 | 1-2 家 |

### 2.4 种子客户策略

| 策略 | 说明 |
|------|------|
| **标杆定价** | 前 5 家客户可享 Pro 版 6 个月半价（¥999/月），换取案例授权 |
| **白手套服务** | 创始人亲自部署和培训，收集第一手产品反馈 |
| **案例产出** | 每个种子客户产出 1 篇案例（使用场景 + 效果数据） |
| **转介绍激励** | 种子客户推荐新客户签约，赠送 1 个月免费 |

### 2.5 月度里程碑

| 月份 | 重点动作 | 交付物 |
|------|---------|--------|
| M1 | 招募首批核心合伙人，完善 Demo 环境 | 3 位核心合伙人到位 |
| M2 | 创始人签第 1-3 个种子客户 | 3 个付费客户 |
| M3 | 核心合伙人开始签客户，招募城市合伙人 | 5 个客户 + 2 城市合伙人 |
| M4 | 产出第一批客户案例 | 3 篇案例文档 |
| M5 | 城市合伙人开始签约 | 8 个客户 + 5 城市合伙人 |
| M6 | PMF 验证回顾，决定是否进入 Phase 2 | 10 个客户，PMF 报告 |

### 2.6 PMF 验证标准

以下 **4 项中满足 3 项** = PMF 已验证，可进入 Phase 2：

| 指标 | 标准 | 原因 |
|------|------|------|
| 客户续费率 | ≥ 70% | 客户真的觉得有用 |
| NPS | ≥ 40 | 客户愿意推荐 |
| 销售周期 | ≤ 3 周（B 级客户） | 产品 market fit 好 |
| 自然增长 | ≥ 20% 客户来自转介绍 | 口碑效应启动 |

## 三、Phase 2 增长期（第 7-12 月）— 跑通渠道

### 目标

| 指标 | 目标值 |
|------|:------:|
| 付费企业客户 | **100 家** |
| MRR | **¥200,000** |
| 城市合伙人 | **20 人** |
| 覆盖城市 | **10 城** |
| GitHub Stars | **5,000** |

### 3.1 城市拓展计划

| 批次 | 城市 | 时间 | 城市合伙人数 |
|------|------|------|:----------:|
| 第 1 批 | Phase 1 验证城市 | 已有 | 5 |
| 第 2 批 | 上海、北京、广州、成都 | M7-M9 | 8 |
| 第 3 批 | 武汉、南京、苏州 | M10-M12 | 7 |

### 3.2 渠道规模化

| 动作 | 说明 |
|------|------|
| 城市合伙人招募 | 每月招募 3-5 人，建立标准化培训流程 |
| 城市合伙人培训 | 入职培训 1 天（线上） + 每周集体答疑 |
| 销售物料标准化 | 产品手册、Demo 环境、报价单模板全部就绪 |
| 佣金即时结算 | Queen City Portal 上线，佣金透明可查 |
| 标杆案例复制 | 按行业整理案例集，城市合伙人直接使用 |

### 3.3 获客渠道组合

| 渠道 | 占比 | 月获客 | 说明 |
|------|:----:|:------:|------|
| 城市合伙人 | 50% | 8 家 | 核心渠道 |
| 核心合伙人直签 | 20% | 3 家 | 大客户/战略客户 |
| 开源社区转化 | 15% | 2 家 | GitHub → 企业试用 → 付费 |
| 内容营销 | 10% | 1-2 家 | 技术博客、行业白皮书 |
| 转介绍 | 5% | 1 家 | 老客户推荐 |

### 3.4 内容营销计划

| 频率 | 内容类型 | 渠道 | 目标 |
|------|---------|------|------|
| 每周 1 篇 | 技术博客（AI Agent 实践） | 公众号 + 知乎 + 掘金 | 开发者认知 |
| 每月 1 篇 | 行业方案（制造/教育/法律） | 公众号 + 官网 | 企业决策者 |
| 每月 1 场 | AI 应用 Webinar | 腾讯会议/飞书 | 线索获取 |
| 每季度 1 份 | 行业白皮书 | 官网下载（留资） | 精准线索 |

## 四、Phase 3 规模化（第 13-24 月）— 全国覆盖

### 目标

| 指标 | 目标值 |
|------|:------:|
| 付费企业客户 | **500 家** |
| ARR | **¥18,000,000** |
| 城市合伙人 | **100 人** |
| 覆盖城市 | **30 城** |

### 4.1 关键动作

| 动作 | 说明 |
|------|------|
| 城市合伙人分层管理 | 铜/银/金/钻石四级，头部合伙人给更多资源 |
| 行业解决方案包 | 制造/教育/法律/金融 4 大行业标准化方案 |
| 战略合作 | 与 2-3 家 IT 服务商/云厂商建立合作 |
| 白牌客户拓展 | 10 家白牌客户，每家覆盖 10-50 企业 |
| 品牌活动 | 每季度 1 场线下行业峰会 |

## 六、关键风险与应对

| 风险 | 应对 |
|------|------|
| 种子客户找不到 | 创始人亲自跑，前 5 家不计成本签下来 |
| 城市合伙人招不到 | 降低门槛 + 首月保底佣金 ¥3,000 |
| 城市合伙人不活跃 | 6 个月 0 签约 → 自动终止；每周群内分享签约案例 |
| 客户续费率低 | 免费首月回访 + 客户成功手册（见 `customer-success.md`） |
| 竞品低价抢客 | 不打价格战，强调管控价值 + 开源透明 + 私有部署 |
