## 二、P0 合同详细要点

### 2.1 《劳动合同》— 核心合伙人

| 条款 | 要点 |
|------|------|
| 合同类型 | 固定期限劳动合同（首签 3 年） |
| 试用期 | 90 天，试用期薪资 = 转正薪资 80% |
| 薪酬结构 | 基础薪资 + 绩效佣金（双轨制：A 轨/B 轨，详见 `partner-recruitment.md`） |
| 社保公积金 | 按当地标准全额缴纳 |
| 工作地点 | [城市] + 远程办公灵活安排 |
| 知识产权 | 工作期间产生的知识产权归公司所有 |
| 解除条件 | 法定 + 协商，离职提前 30 天书面通知 |

> ⚠️ 双轨制薪酬需在劳动合同中明确约定计算方式，避免劳动仲裁争议。

### 2.2 《股权期权授予协议》— 核心合伙人

| 条款 | 要点 |
|------|------|
| 期权数量 | 占总股本 1-5%（从 19% 期权池中授予） |
| 行权价格 | 按授予时最近一轮估值的公允价确定 |
| 归属规则 | 4 年归属，1 年 Cliff，之后每月归属 |
| 离职处理 | 已归属 → 保留（公司有回购权，按估值 70%）；未归属 → 收回 |
| 竞业期间 | 竞业禁止期内继续归属（作为竞业补偿一部分） |
| 稀释保护 | 后续融资按比例稀释，无反稀释条款 |
| 税务 | 行权时按"工资薪金"或"股权激励"纳税，公司协助申报 |

> ⚠️ 期权协议需要律师审核，确保符合《公司法》和税务规定。推荐使用有限合伙（LP）持股平台。

### 2.3 《竞业禁止协议》— 核心合伙人

| 条款 | 要点 |
|------|------|
| 竞业期限 | 在职期间 + 离职后 12 个月 |
| 竞业范围 | AI Agent 平台、企业 AI SaaS、同类开源项目 |
| 竞业补偿 | 离职后竞业期间按月支付离职前 12 个月平均薪资的 30% |
| 违约金 | 返还已支付竞业补偿 + 赔偿金（具体金额协议约定） |
| 地域范围 | 中国大陆 |

> ⚠️ 根据《劳动合同法》第 23/24 条，竞业禁止协议必须支付经济补偿，否则无效。

### 2.4 《保密协议（NDA）》— 通用

| 条款 | 要点 |
|------|------|
| 保密范围 | 商业计划、客户信息、技术架构、定价策略、财务数据 |
| 保密期限 | 合作期间 + 终止后 3 年 |
| 例外 | 公开信息、独立开发、法律要求披露 |
| 违约责任 | 赔偿实际损失 + 违约金 |
| 适用对象 | 核心合伙人、城市合伙人、潜在投资人、合作方 |

### 2.5 《城市合伙人合作协议》

| 条款 | 要点 |
|------|------|
| 合作性质 | 独立合作关系，非劳动关系，非代理关系 |
| 合作内容 | 推广和销售 StarClaw 企业产品 |
| 佣金比例 | 首年 40%、续费 25%、星能 30%、增值 60%（可升级阶梯） |
| 结算方式 | 月结，每月 5 号出账，10 号前打款，最低 ¥500 |
| 税务 | 平台代扣代缴个税；对公合作需提供发票 |
| 客户保护 | 12 个月独占保护期 |
| 最低售价 | 不低于官网标价 80% |
| 考核 | 首 6 个月签约 ≥1 家客户，否则平台可终止 |
| 终止条件 | 任一方提前 30 天书面通知；违规行为可立即终止 |
| 竞品限制 | 非排他，但不得同时推广直接竞品 |

> ⚠️ 必须明确**非劳动关系**，避免城市合伙人主张劳动权益。合同措辞需律师审核。

### 2.6 《企业客户服务协议》

| 条款 | 要点 |
|------|------|
| 服务内容 | Overlord 企业 AI 智能体订阅服务 |
| 套餐与定价 | 引用 `pricing.md` 标准定价 |
| 付款方式 | 月付/年付，到期自动续费（提前 30 天通知取消） |
| SLA | Community/Starter: 无 SLA；Pro: 99.5%；Enterprise+: 99.9% |
| 数据权属 | 客户数据归客户所有，平台不使用 |
| 数据安全 | 私有部署数据不出客户网络；SaaS 部署逻辑隔离 + 加密 |
| 知识产权 | 平台代码归平台所有；客户创建的 Agent/知识库归客户 |
| 退款 | 年付未使用部分按比例退款；月付不退 |
| 终止 | 到期不续费自动终止；违约可立即终止 |
| 争议解决 | [公司所在地] 仲裁委员会仲裁 |

## 三、P1 合同简要说明

### 3.1 《服务等级协议（SLA）》

作为《企业客户服务协议》的附件，明确：
- 可用性承诺（99.5% / 99.9%）
- 故障响应时间（Pro: 4 小时；Enterprise: 1 小时）
- 赔偿方案（服务中断超 SLA → 按比例延长服务期）
- 排除项（不可抗力、客户自身原因、计划维护窗口）

### 3.2 《白牌定制服务协议》

在《企业客户服务协议》基础上增加：
- 定制范围和交付物清单
- 品牌素材提供和审核流程
- 交付验收标准和时间
- 知识产权归属（平台代码归平台；定制部分按约定）
- 保密条款（不得向白牌客户的终端用户透露 StarClaw）

### 3.3 《数据处理协议（DPA）》

当客户通过 StarClaw 处理个人数据时需要签署：
- 数据处理目的和范围
- 数据存储地点和期限
- 数据安全措施
- 数据泄露通知义务
- 符合《个人信息保护法》要求

### 3.4 《天使轮投资协议》

- 投资金额和估值
- 股权比例和股份类型（AB 股）
- 投资人权利（信息权、反稀释、优先清算）
- 创始人锁定期
- 对赌条款（如有）
- 详见 `equity-structure.md` 融资规划

## 四、签约流程

```
合同模板准备 → 商务条款确认 → 律师审核 → 定稿 → 双方签署 → 归档
                                                    │
                                          电子签（推荐：法大大/e签宝）
                                          或线下签署（需扫描存档）
```

**合同管理要求：**
- 所有合同电子存档（PDF）
- 命名规范：`[日期]_[合同类型]_[对方名称].pdf`
- 存储位置：Queen Admin 合同管理模块（上线前用共享网盘）
- 到期提醒：合同到期前 30 天自动提醒
