# StarClaw 客户案例模板

> 内部文件 — 标准化客户案例写作指南，前 5 个客户必须产出案例

---

## 一、案例用途

| 用途 | 场景 |
|------|------|
| 销售物料 | Demo 后发给客户参考，增强信任 |
| 官网展示 | 首页/案例页，提升转化率 |
| 公众号内容 | 行业方案类长文素材 |
| 城市合伙人工具 | 合伙人拿着案例去谈客户 |
| 投资人材料 | BP 附件，证明 PMF |

---

## 二、案例结构（标准模板）

### 封面信息

```
客户名称：[公司名 / 匿名：某 XX 行业企业]
行业：[制造 / 教育 / 法律 / 金融 / 电商 / 其他]
规模：[XX 人]
套餐：[Starter / Pro / Enterprise / White-Label]
部署方式：[SaaS / 私有云 / 本地部署]
使用时间：[X 个月]
```

---

### 一、客户背景（100 字）

> 简要介绍客户是谁、做什么、多大规模。

**模板：**
```
[公司名] 是一家位于 [城市] 的 [行业] 企业，拥有 [X] 名员工。
公司主营 [业务]，年营收约 [X] 万元。
```

### 二、痛点与挑战（200 字）

> 客户在使用 AI 之前/使用其他方案时遇到了什么问题？

**常见痛点模板（选 2-3 个）：**

| 痛点 | 描述模板 |
|------|---------|
| 数据安全 | "员工将公司内部文档直接粘贴到 ChatGPT，存在数据泄露风险" |
| 无法管控 | "不知道谁在用 AI、用了多少、花了多少钱" |
| 成本失控 | "各部门各自购买 AI 工具，月度 API 费用高达 ¥XX" |
| 无法审计 | "金融/医疗行业合规要求，AI 使用需要留痕审计" |
| 效率低 | "XX 业务流程人工处理需要 X 天" |
| 工具碎片化 | "研发用 GitHub Copilot、市场用 ChatGPT、客服用智能客服，无法统一管理" |

### 三、解决方案（300 字）

> StarClaw 怎么解决客户的问题？用了哪些功能？

**模板：**
```
[公司名] 选择了 StarClaw [套餐] 版，采用 [部署方式] 部署。

核心配置：
- [X] 个 AI 节点，覆盖 [X] 个部门
- 接入模型：[DeepSeek V3 / GPT-4o / Qwen 2.5 / ...]

部署过程：
- 从签约到上线仅用 [X] 天
- [描述部署过程中的亮点或客户反馈]
```

### 五、客户评价（1-2 句话）

> 客户决策人的直接引用，越具体越好。

**获取方法：** 回访时直接问客户——
```
"如果要向您的同行推荐 StarClaw，您会怎么说？"
```

**好的引用示例：**
- "以前我最怕的是不知道员工把什么发给了 ChatGPT。现在所有 AI 对话都在我们自己的服务器上，睡得安稳多了。" — XX 公司 CTO
- "¥2,000 一个月，200 人都能用 AI，比之前各部门零散买工具省了一半。" — XX 公司 IT 总监

**差的引用示例（避免）：**
- "StarClaw 很好用。" （太空泛）
- "推荐！" （没有信息量）

### 六、总结（50 字）

**模板：**
```
[公司名] 通过 StarClaw [套餐] 版，实现了 [核心效果]，
[关键指标] 提升/降低了 [XX%]。
```

## 三、案例写作流程

```
1. 签约时  → 告知客户可能邀请撰写案例（种子客户享半价的条件之一）
2. 上线 D30 → 首月回访时收集初步数据
3. 上线 D90 → 正式案例访谈（30 分钟，远程/当面）
4. 3 天内   → 完成案例初稿
5. 发给客户 → 客户审核确认（重点：数据准确性、公司名是否可公开）
6. 修改定稿 → 发布到官网/公众号
```

### 案例访谈问题清单

| 序号 | 问题 | 对应章节 |
|:----:|------|---------|
| 1 | 贵司之前是怎么用 AI 的？遇到什么问题？ | 痛点 |
| 2 | 为什么选择 StarClaw？考虑过哪些替代方案？ | 方案 |
| 3 | 部署过程顺利吗？有没有让你印象深刻的地方？ | 方案 |
| 4 | 现在哪些部门在用？主要用来做什么？ | 方案 |
| 5 | 使用后效果怎么样？有没有具体的数据变化？ | 效果 |
| 6 | 如果要向同行推荐，您会怎么说？ | 评价 |
| 7 | 接下来有什么计划？想增加什么功能？ | 增购机会 |

## 五、案例产出目标

| 阶段 | 时间 | 案例数 | 行业覆盖 |
|------|------|:------:|---------|
| 种子期 | M1-M6 | **5 篇** | 制造 + 教育 + 法律 |
| 增长期 | M7-M12 | **15 篇** | 扩展到金融、电商、医疗 |
| 规模化 | M13-M24 | **30 篇** | 全行业覆盖 |

> **目标：每个行业至少 3 篇案例**，城市合伙人可以按行业匹配给潜在客户。
