# StarClaw 城市合伙人销售提成制度与合作方式

> 版本：v1.0 | 日期：2026 年 3 月 | 本文件可作为《城市合伙人合作协议》附件

---

## 一、合作关系定义

### 1.1 合作模式

城市合伙人与 StarClaw 平台（以下简称"平台"）签订《城市合伙人合作协议》，为**独立商事合作关系**，非劳动雇佣关系。

```
平台（StarClaw）
  │
  ├── 提供：产品、技术、部署、售后、结算系统
  │
  └── 城市合伙人（独立主体）
        │
        ├── 职责：获客、售前咨询、合同签约、客户维护
        └── 权利：按约定比例获取销售佣金
              │
              └── 客户（企业）
                    └── 与平台签订《产品服务协议》
```

### 1.2 三方关系

| 关系 | 说明 |
|------|------|
| 平台 ↔ 客户 | 产品服务合同（平台为服务提供方） |
| 平台 ↔ 城市合伙人 | 渠道合作协议（佣金结算关系） |
| 城市合伙人 → 客户 | 销售推荐关系（不直接签产品合同） |

> 客户的产品合同统一与平台签订，城市合伙人不代表平台签订产品服务合同，除非获得平台书面授权。

### 1.3 合作期限

| 项目 | 规则 |
|------|------|
| 合同期限 | 首签 1 年，到期自动续约（除非任一方提前 30 天书面通知不续） |
| 试用期 | 首 6 个月为观察期，须签约 ≥1 家客户 |
| 非排他 | 城市合伙人可同时代理其他非直接竞品产品 |
| 竞品限制 | **不得同时代理** Dify 企业版、FastGPT 商业版、MaxKB 企业版等直接竞品 |

## 二、销售提成制度

### 2.1 佣金类型总览

| 收入类型 | 佣金基数 | 首年佣金率 | 续费佣金率 | 说明 |
|---------|---------|:--------:|:--------:|------|
| **节点订阅费** | 客户年付合同额 | **40%** | **25%** | 主要收入来源，按客户实际付款 |
| **星能消耗费** | 客户月度 AI 推理消耗 | **30%** | **30%** | 用量越大你越赚，首年续费同比例 |
| **增值服务费** | 由城市合伙人自行交付的定制/培训 | **60%** | — | 你自己的交付能力直接变现 |
| **白牌分成** | 白牌下终端客户全部收入 | — | — | 60/40 分成，详见 §2.5 |

### 2.2 节点订阅费佣金计算

节点订阅费是城市合伙人的核心收入来源。

**计算公式：**

```
月度佣金 = 客户当月实付订阅额 × 佣金比例

首年佣金比例 = 40%（铜级基准，升级见 §2.4 阶梯制度）
续费佣金比例 = 25%（铜级基准）
```

**示例：**

| 客户套餐 | 年价 | 折合月价 | 首年月佣金 | 续费月佣金 |
|---------|:----:|:------:|:--------:|:--------:|
| Starter | ¥4,790/年 | ≈¥399/月 | ¥160 | ¥100 |
| Pro | ¥19,190/年 | ≈¥1,599/月 | ¥640 | ¥400 |
| Enterprise | ¥47,990/年 | ≈¥3,999/月 | ¥1,600 | ¥1,000 |
| White-Label | 面议 | ≈¥9,999+/月 | 按实际合同额 | 按实际合同额 |

**首年 vs 续费界定：**

| 场景 | 判定 |
|------|------|
| 客户首次签约后连续 12 个自然月 | 首年费率 |
| 第 13 个月起 | 续费费率 |
| 客户中断后重新签约 | 重新按首年计，但保护期内仍归原合伙人 |
| 客户升级套餐 | 差额部分按当前期间（首年/续费）费率 |
| 客户降级套餐 | 按降级后实付额计算 |

### 2.3 星能消耗费佣金

星能（star-ai.net API 调用）消耗由系统自动计量，城市合伙人的客户在平台产生的 AI 推理消耗，城市合伙人按 **30%** 提成，不区分首年续费。

```
月度星能佣金 = 归属客户当月星能消耗总额 × 30%
```

### 2.4 阶梯佣金制度

当城市合伙人月度归属客户总流水（订阅费 + 星能消耗）达到一定规模，自动升级佣金等级：

| 等级 | 月度总流水门槛 | 节点订阅-首年 | 节点订阅-续费 | 星能消耗 | 额外权益 |
|:----:|:----------:|:----------:|:----------:|:------:|---------|
| 🥉 **铜级** | < ¥50,000 | 40% | 25% | 30% | 基础权益 |
| 🥈 **银级** | ≥ ¥50,000 | 43% | 28% | 32% | 优先技术支持 |
| 🥇 **金级** | ≥ ¥200,000 | 45% | 30% | 35% | 专属客户经理 + 联合市场活动 |
| 💎 **钻石** | ≥ ¥500,000 | 48% | 32% | 38% | 白牌免费升级 + 季度培训 |

**升降级规则：**

| 规则 | 说明 |
|------|------|
| 升级判定 | 连续 2 个自然月达标即升级，次月 1 日生效 |
| 降级保护 | 连续 3 个自然月未达标才降级（避免波动） |
| 新人保护 | 入驻首 3 个月享银级待遇（无需达标） |
| 等级上限 | 无上限，钻石级以上可申请"战略合伙人"定制方案 |

### 2.5 增值服务费

城市合伙人可自行为客户提供以下增值服务，平台不参与交付，佣金 **60%** 归城市合伙人：

| 增值服务 | 定价建议 | 说明 |
|---------|:-------:|------|
| AI 应用培训 | ¥5,000-20,000/次 | 企业 AI 使用培训 |
| Agent 定制开发 | ¥10,000-50,000/个 | 基于平台搭建行业 Agent |
| 知识库建设 | ¥5,000-30,000 | 帮客户整理、导入企业知识库 |
| 工作流配置 | ¥3,000-15,000/个 | 配置业务自动化工作流 |
| 年度运维包 | ¥12,000-60,000/年 | 持续优化、模型调优 |

> 增值服务由城市合伙人自行报价和交付，平台收取 40% 平台服务费，佣金 = 服务收入 × 60%。

### 2.6 白牌合伙方案

年度签约客户 ≥5 家的城市合伙人可申请**白牌合伙**，以自有品牌向终端客户销售：

| 项目 | 规则 |
|------|------|
| 准入条件 | 累计签约 ≥5 家客户 + 月度流水 ≥¥50,000 |
| 定制费 | **¥0**（正常白牌定制费 ¥20,000 全免） |
| 月度平台费 | **¥0**（正常月费 ¥9,999 全免） |
| 分成模式 | 终端客户全部收入 **60%** 归城市合伙人，**40%** 归平台 |
| 品牌定制 | Logo、配色、名称、域名全套替换 |
| 独立性 | 终端客户看到的是你的品牌 |

**白牌 vs 标准模式对比：**

| 维度 | 标准代理 | 白牌合伙 |
|------|---------|---------|
| 客户看到 | StarClaw 品牌 | 你的品牌 |
| 订阅佣金 | 40%/25% | 全部收入 60% |
| 定制费用 | 无 | ¥0（免费） |
| 适合 | 纯销售型合伙人 | 有 IT 服务能力的公司/个人 |

## 三、结算规则

### 3.1 结算周期与流程

```
每月 1-3 日    系统自动汇总上月佣金数据
每月 5 日      平台出具《月度佣金账单》
每月 5-7 日    城市合伙人在后台确认或申诉
每月 10 日     平台完成打款
```

### 3.2 结算方式

| 项目 | 规则 |
|------|------|
| 打款方式 | 对公转账（优先）/ 个人银行账户 |
| 发票要求 | 对公需提供等额增值税发票；个人由平台代扣代缴 |
| 最低结算额 | ¥500/月（未达标累计至下月） |
| 结算币种 | 人民币（¥） |
| 争议处理 | 账单确认期内提出申诉，平台 5 个工作日内核实回复 |

### 3.3 税务处理

| 主体类型 | 税务处理 |
|---------|---------|
| 个体工商户 / 个人 | 平台按"劳务报酬"代扣代缴个人所得税 |
| 有限公司 | 城市合伙人公司开具增值税发票，自行纳税 |
| 个人独资企业 | 按经营所得自行申报 |

> 建议月佣金 ≥¥10,000 的城市合伙人注册个体工商户或个人独资企业，享受更优税率。

## 四、客户保护与归属

### 4.1 客户归属原则

| 规则 | 说明 |
|------|------|
| 首签归属 | 客户签约时绑定推荐的城市合伙人，系统自动记录 |
| 保护期 | **12 个自然月**，保护期内客户续费、升级、追加均归原合伙人 |
| 保护期续延 | 客户续费后保护期自动顺延 12 个月 |
| 跨区保护 | 城市合伙人按注册城市划分，不得跨区拓客 |
| 冲突仲裁 | 以系统记录的首次推荐码（ref_code）为准 |

### 4.2 特殊场景

| 场景 | 处理方式 |
|------|---------|
| 客户主动联系平台（无推荐码） | 归属平台直签客户，不计入任何城市合伙人 |
| 同一客户被多人推荐 | 以首次有效推荐（系统记录）为准 |
| 客户保护期满后流失再回 | 无推荐码则归平台，有新推荐码则归新合伙人 |
| 城市合伙人退出后客户续费 | 退出后 3 个月内续费仍结算佣金，3 个月后不再结算 |

### 4.3 大客户报备制度

| 规则 | 说明 |
|------|------|
| 报备标准 | 年合同额预估 ≥¥100,000 的客户 |
| 报备方式 | 城市合伙人后台提交报备，24 小时内审核 |
| 报备有效期 | 60 天，到期未签约可申请续期一次（30 天） |
| 平台协助 | 报备后平台提供售前技术支持、方案设计、定价建议 |
| 佣金不变 | 平台协助不影响城市合伙人佣金比例 |

## 五、最低售价与定价规范

### 5.1 最低售价

| 规则 | 说明 |
|------|------|
| 最低折扣 | 不得低于官网标价的 **80%**（即最多打 8 折） |
| 违规处理 | 首次警告，二次暂停佣金结算，三次解除合作 |
| 特批机制 | 大客户（年 ≥¥100K）可申请特价，需平台审批 |

### 5.2 各套餐标价与最低价

| 套餐 | 官网年价 | 合伙人最低报价（8折） | 首年年佣金（铜级 40%） |
|------|:-------:|:----------------:|:------------------:|
| Community | 免费 | — | — |
| Starter | ¥4,790/年 | ¥3,832/年 | ¥1,533-1,916 |
| Pro | ¥19,190/年 | ¥15,352/年 | ¥6,141-7,676 |
| Enterprise | ¥47,990/年 | ¥38,392/年 | ¥15,357-19,196 |
| White-Label | 面议 | 面议 | 按实际合同额 |

> 佣金按客户实际支付金额计算（非标价），因此折扣越多佣金越少，建议尽量按标价签约。
> 全部付费套餐按年订阅收费。

## 六、考核与退出

### 6.1 业绩考核

| 周期 | 最低要求 | 未达标处理 |
|------|---------|----------|
| 首 6 个月（观察期） | 签约 ≥1 家客户 | 书面提醒 + 延长观察 3 个月 |
| 延长观察期（第 7-9 月） | 签约 ≥1 家客户 | 解除合作协议 |
| 年度考核 | 年度新签 ≥3 家客户 | 降为"休眠合伙人"（保留续费佣金，暂停新签权限） |

### 6.2 违规行为

| 行为 | 处理 |
|------|------|
| 私下承诺平台未授权的功能/服务 | 警告 + 承担客户投诉责任 |
| 低于最低售价签约 | 警告 → 暂停 → 解除 |
| 代理直接竞品 | 解除合作，30 天内结清佣金 |
| 虚假签约（刷单） | 立即解除，追回佣金，保留法律追究权 |
| 泄露平台商业机密 | 立即解除，依法追究 |

### 6.3 退出机制

| 场景 | 处理 |
|------|------|
| 主动退出 | 提前 30 天书面通知，存量客户续费佣金继续结算 3 个月 |
| 平台解除 | 提前 15 天通知，结清已确认佣金 |
| 客户交接 | 退出后客户由平台接管或分配给其他合伙人 |
| 保密义务 | 退出后 12 个月内不得泄露平台客户信息、定价策略 |

## 八、收入模拟场景

### 场景 A：兼职型（月投入 20 小时）

```
客户获取：1 家/月，均价 ¥2,000/月（Starter + Pro 混合）

第 6 个月：
  活跃客户：6 家
  首年佣金：6 × ¥2,000 × 40% = ¥4,800/月

第 12 个月：
  活跃客户：12 家（假设 0 流失）
  首年佣金：6 × ¥2,000 × 40% = ¥4,800/月
  续费佣金：6 × ¥2,000 × 25% = ¥3,000/月
  月收入合计：¥7,800/月
  年收入约：¥56,000+
```

### 场景 B：全职型（月投入 160 小时）

```
客户获取：3 家/月，均价 ¥5,000/月（Pro 为主）

第 6 个月：
  活跃客户：18 家
  月佣金：18 × ¥5,000 × 40% = ¥36,000/月
  已达银级（流水 ¥90,000），佣金率升至 43%
  实际月佣金：18 × ¥5,000 × 43% = ¥38,700/月

第 12 个月：
  活跃客户：36 家
  首年佣金：18 × ¥5,000 × 43% = ¥38,700
  续费佣金：18 × ¥5,000 × 28% = ¥25,200
  月收入合计：¥63,900/月
  年收入约：¥500,000+
```

### 场景 C：团队型（IT 服务公司，3 人销售团队）

```
客户获取：8 家/月，均价 ¥8,000/月（Pro + Enterprise 混合）

第 6 个月：
  活跃客户：48 家，月流水 ¥384,000
  已达金级（佣金率 45%/30%）
  月佣金约：¥150,000+

第 12 个月：
  活跃客户：96 家，月流水 ¥768,000
  钻石级（佣金率 48%/32%）
  月佣金约：¥300,000+
  可申请白牌合伙 → 60% 分成 → 收入更高

  叠加增值服务（培训/定制）：
  年增值收入 × 60% 约 ¥200,000-500,000

  团队年收入：¥2,000,000-4,000,000+
```

> ⚠️ 以上均为假设测算，不构成收益承诺。实际收入取决于个人/团队能力、市场环境、客户行业等因素。

## 九、与核心合伙人的关系

| 维度 | 城市合伙人 | 核心合伙人 |
|------|----------|----------|
| 身份 | 外部渠道合作方 | 公司内部团队（员工） |
| 合同 | 《城市合伙人合作协议》 | 《劳动合同》+《期权协议》 |
| 底薪 | 无 | A轨 ¥5K / B轨 ¥20K-40K |
| 期权 | 无 | 1-5% |
| 社保 | 无（自行缴纳） | 公司全额缴纳 |
| 排他 | 非排他（竞品除外） | 全职排他 |
| 佣金来源 | 平台直接结算 | 薪酬组成部分 |
| 管理关系 | 城市合伙人由平台分配的核心合伙人辅导 | 直接管理城市合伙人 |

> 城市合伙人与核心合伙人不是上下级关系。核心合伙人收取的"渠道管理费"由平台支付，不从城市合伙人佣金中扣除。两者佣金完全独立核算。

## 十、常见问题

**Q：需要交保证金吗？**
A：不需要。零门槛加入，无保证金，无囤货。

**Q：可以兼职做吗？**
A：可以。城市合伙人无出勤要求，按业绩考核。

**Q：我不懂技术，能卖吗？**
A：能。平台负责全部技术工作（演示、部署、维护），你只需找客户、谈需求、签合同。

**Q：如果我签的客户不续费，还有佣金吗？**
A：不续费则不再产生佣金。建议维护客户关系以提高续费率。

**Q：能同时做 Dify 代理吗？**
A：不能同时代理直接竞品（Dify 企业版、FastGPT 商业版、MaxKB 企业版）。其他非竞品不受限制。

**Q：佣金发现算错了怎么办？**
A：每月 5-7 日为账单确认期，可在后台提出申诉，平台 5 个工作日内核实。

**Q：退出后客户怎么办？**
A：退出后存量客户续费佣金继续结算 3 个月，之后客户由平台接管。
