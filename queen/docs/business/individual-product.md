## 开发者 API

star-ai.net 提供 OpenAI 兼容 API，一个 Key 调用所有模型：

```bash
curl https://api.star-ai.net/v1/chat/completions \
  -H "Authorization: Bearer YOUR_STAR_AI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v3",
    "messages": [{"role": "user", "content": "你好"}]
  }'
```

**支持：**
- OpenAI SDK 直接替换 `base_url` 即可
- 流式输出（SSE）
- Function Calling / Tool Use
- Vision（图片输入）
- Embeddings
