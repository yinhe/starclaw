# StarClaw 股权架构与融资规划

> 群星模式 — 1+5+30 虫族合伙人股权分配体系

---

## 一、核心原则

1. **群星模式** — 1（虫后）+ 5（脑虫）+ 30（领主）= 36 人共持 51%，用人数和扁平化吸引人才
2. **创始人靠控制权领导** — AB 股 1:30 投票权，经济权让利、投票权不让
3. **零底薪，纯佣金 + 股权** — 全员合伙人模式，不消耗现金，用收入弹性和股权上行驱动
4. **活下来比什么都重要** — 每一轮融资金额 = 确保 18 个月生存期
5. **不见兔子不撒鹰** — 每轮融资对应明确的业务里程碑

| 档位 | 虫族代号 | 人数 | 每人股权 | 小计 | 角色定位 |

| | | **36** | | **51%** | |

> **设计哲学：** 创始人只留 6% 经济权，把 45% 分给 35 个合伙人。脑虫 3% 吸引顶尖联合创始人，领主 1% 驱动全国裂变。用 AB 股 1:30 保持控制权。36 个人都是老板，每人至少 1%，IPO 时 1% = ¥1 亿。
>
> **脑虫选举机制：** 5 个脑虫席位由全体团队合伙人投票选出，Queen 运营平台发起选举，得票前 5 名当选。可定期轮换，确保能者上席。

### 2.3 AB 股与投票权

```
A 类股（创始人专属）：1 股 = 30 票投票权
B 类股（所有其他人）：1 股 = 1 票投票权

创始投票权计算：
  虫后   6% × 30 = 180 票
  脑虫  15% × 1  =  15 票
  领主  30% × 1  =  30 票
  投资人 49% × 1  =  49 票
  ──────────────────────
  总票数 = 274 票
  虫后占比 = 180/274 = 65.7% ✅ 绝对控制

各轮融资后虫后投票权（1:30，单独过半）：
  创始      → 65.7% ✅
  Pre-A 后  → 62.8% ✅
  A 轮后    → 59.4% ✅
  B 轮后    → 55.8% ✅
  C 轮后    → 53.3% ✅
  IPO 后    → 49.7% ← 差 0.3%，加一致行动人即可

  IPO 后虫后+脑虫一致行动人 = 53.9% ✅

  ⚠️ 如需虫后全程单独过半，可提高到 1:35
     → IPO 后 = 53.6% ✅

先例：Google、Meta、京东、小米、拼多多、理想汽车均采用此结构
适用：开曼 / BVI 架构（港股/美股），国内 VIE 协议控制亦可实现
```

### 2.6 领主 Overlord — 团队合伙人（30 人 × 1%）

领主是群星模式的**裂变引擎**。30 个名额，每人 1% 股权，遍布全国快速铺开。领主中表现优异者可由团队投票晒升为脑虫。

| 项目 | 内容 |
|------|------|
| 总名额 | **30 人** |
| 每人股权 | **1%** |
| 底薪 | **¥0**（零底薪） |
| 直签客户佣金 | **70%** |
| 城市合伙人管理费 | 管理的城市合伙人客户首年 **15%** / 续费 **8%** |
| 推荐奖励 | 推荐新领主加入，其前 12 月佣金的 **10%** |

**领主归属规则（业绩驱动，不是坐等）：**

```
与传统 4 年时间 vesting 不同，领主采用「业绩归属」：

每完成 1 个里程碑 = 归属 25%，共 4 个 = 100%

里程碑（满足任一即算达成）：
  ✅ 直签 3 家付费客户
  ✅ 招募 2 名城市合伙人且各签约 ≥1 家
  ✅ 单季度佣金收入 ≥ ¥30,000

效果：
  干得快 → 最快 3 个月 100% 归属（4 个里程碑全达成）
  干得慢 → 12 个月内至少完成 1 个里程碑
  不干活 → 12 个月内 0 个里程碑 = 收回股权，退出

离职处理：
  已归属部分 → 保留（公司有回购权，按最近一轮估值的 70%）
  未归属部分 → 收回池子，分配给新领主
```

**领主招募节奏：**

| 阶段 | 时间 | 招募目标 | 说明 |
|------|------|:-------:|------|
| 种子期 | 0-6 个月 | 领主 #1-6 | 创始人直接招募，验证模式 |
| 扩张期 | 6-12 个月 | 领主 #7-15 | 脑虫各带 1-2 人 |
| 规模期 | 12-24 个月 | 领主 #16-30 | 老领主推荐 + 公开招募 |

## 四、生存底线 — 每个阶段的死亡线

```
⚠️  创业公司 90% 死于现金流断裂，不是死于竞争。

群星模式的核心优势：零薪资 = 极低现金消耗 = 超长生存期。
36 个合伙人靠佣金养活自己，公司只需要承担基础设施和运营成本。
```

| 阶段 | 账上现金 | 月烧钱 | 生存期 | 死亡线（必须达到） |
|------|:-------:|:-----:|:-----:|:---:|
| 天使轮后 | ¥500 万 | ¥6 万 | **83 月** | 第 24 月：月收入 ¥5 万 |
| Pre-A 后 | ¥1,000 万 | ¥25 万 | 40 月 | 第 12 月：月收入 ¥30 万 |
| A 轮后 | ¥4,500 万 | ¥70 万 | **64 月** | 第 18 月：月收入 ¥200 万 |
| B 轮后 | ¥1.5 亿 | ¥250 万 | **60 月** | 第 18 月：月收入 ¥800 万 |
| C 轮后 | ¥3 亿 | ¥800 万 | 37 月 | 第 12 月：月度盈亏平衡 |

> 💡 对比传统模式：天使轮后月烧 ¥25 万（4 人薪资），只能活 20 月。群星模式月烧 ¥6 万，可活 83 月。**生存期是传统模式的 4 倍。**

**保命规则：**

1. **永远留 6 个月的钱不动** — 账上低于 6 个月开支时立即启动下一轮融资
2. **融资永远比你想象的慢 2 倍** — 预计 3 个月关闭的融资，预留 6 个月
3. **收入 > 融资** — 从 Pre-A 开始，每月要有真实收入，不能纯靠烧钱
4. **合伙人自养** — 36 个合伙人靠佣金收入养活自己，公司不承担工资成本

## 五、利润分配策略

```
群星模式下，所有合伙人（虫后/脑虫/领主）零底薪，收入 = 佣金 + 股权增值。
公司净利润全部再投入增长，直到 B 轮后有稳定正现金流。
```

| 阶段 | 净利润处理 | 合伙人收入来源 |
|------|----------|-------------|

## 六、资方谈判要点

### 6.1 天使资方 49% 的谈判逻辑

```
天使资方拿 49% 经济权，看似很多，但：
  ① 投票权只有 B 类（1:1），虫后 AB 股 1:30 确保控制权
  ② 49% 会随后续融资稀释（IPO 后约 26%）
  ③ 群星模式零薪资 = 极低风险，¥500 万可撑 3 年
  ④ 36 个合伙人的裂变网络 = 极高成长潜力
```

| 策略 | 说法 |
|------|------|
| **AB 股** | "您拿 49% 经济权，但投票权用 B 类股。AI 公司需要创始人有决策权，这是 Google/小米的标准做法。" |
| **对赌** | "我们用业绩对赌：24 个月 ARR 达 ¥500 万，团队不追加稀释；没达到，您可追加 2%。" |
| **分期** | "先投 ¥300 万，看到 PMF 后再追加 ¥200 万。降低您的风险。" |
| **底线** | "团队经济权不低于 51%，投票权通过 AB 股 + 一致行动人协议确保。这是不可谈判的底线。" |

### 6.2 投资人保护条款（可接受）

| 条款 | 可接受 | 说明 |
|------|:-----:|------|
| 董事会席位 | ✅ | 5 人董事会：创始人 3 席 + 资方 1 席 + 独董 1 席 |
| 反稀释条款 | ✅ | 加权平均反稀释（不接受完全棘轮） |
| 优先清算权 | ✅ | 1× 非参与型（资方先拿回本金，剩余按比例分） |
| 拖售权 | ⚠️ | 仅限公司连续 2 年亏损且创始人同意 |
| 一票否决 | ⚠️ | 仅限重大事项（卖公司/增发 >20%/借债 >¥5000 万） |
| 竞业禁止 | ✅ | 创始人在职期间 + 离职后 1 年 |
| 信息权 | ✅ | 季度财报 + 年度审计 |

### 6.3 绝对不能接受的条款

| 条款 | 原因 |
|------|------|
| ❌ 完全棘轮反稀释 | 下一轮估值下降时创始人被极度稀释 |
| ❌ 资方对日常运营一票否决 | 创始人无法正常做决策 |
| ❌ 强制分红条款 | 早期必须全部再投入 |
| ❌ 资方指定 CEO/CTO | 创始人必须保持管理权 |
| ❌ 对赌回购（个人无限连带） | 失败时创始人不应承担无限个人债务 |
