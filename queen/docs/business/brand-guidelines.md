# StarClaw 品牌规范

> 内部文件 — 品牌视觉、语言、虫族术语对外使用边界

---

## 一、品牌基础

### 1.1 品牌名称

| 场景 | 写法 | 说明 |
|------|------|------|
| 英文全称 | **StarClaw** | 首字母大写，一个单词，无空格 |
| 中文全称 | **星爪** | 仅在中文语境下使用 |
| 域名 | starclaw.net | 主域名 |
| 算力平台 | star-ai.net | 算力网关独立品牌 |
| 错误写法 | ~~Star Claw~~、~~starclaw~~、~~STARCLAW~~、~~星抓~~ | 禁止 |

### 1.2 品牌标语

| 用途 | 标语 |
|------|------|
| 主标语（对外） | **让每个企业都拥有自己的 AI 智能体** |
| 开发者标语 | **Your AI, Your Rules** |
| 技术标语 | **开源 · 私有 · 可管控的企业 AI 智能体** |
| 内部标语 | **为虫群而战** |

### 1.3 品牌定位一句话

> StarClaw 是开源的企业级 AI 智能体，帮助企业在私有环境中统一管理多模型 AI 能力，实现团队隔离、用量审计和成本可控。

## 二、视觉规范

### 2.1 品牌色

| 色彩 | 色值 | 用途 |
|------|------|------|
| **星爪紫** | `#7C3AED` (Violet-600) | 主品牌色，Logo、按钮、重点元素 |
| **深空黑** | `#0F172A` (Slate-900) | 背景、正文、标题 |
| **星云灰** | `#64748B` (Slate-500) | 辅助文字、描述 |
| **能量绿** | `#10B981` (Emerald-500) | 成功状态、在线、增长指标 |
| **警告橙** | `#F59E0B` (Amber-500) | 警告、告警 |
| **危险红** | `#EF4444` (Red-500) | 错误、危险操作 |
| **白色** | `#FFFFFF` | 卡片背景、浅色模式 |

> 深色模式以 `#0F172A` 为背景，浅色模式以 `#FFFFFF` 为背景。品牌紫在两种模式下均为主色。

### 2.2 Logo 使用规范

| 规则 | 说明 |
|------|------|
| 最小尺寸 | 宽度不小于 80px |
| 安全空间 | Logo 四周留出 Logo 高度 50% 的空白 |
| 深色背景 | 使用白色 Logo |
| 浅色背景 | 使用紫色/黑色 Logo |
| 禁止 | 拉伸变形、加阴影、改颜色、加描边、旋转 |

### 2.3 字体

| 用途 | 字体 | 备选 |
|------|------|------|
| 英文标题 | **Inter** (Bold/Semibold) | SF Pro Display |
| 英文正文 | **Inter** (Regular) | SF Pro Text |
| 中文标题 | **思源黑体** (Bold) | 苹方-简 (Semibold) |
| 中文正文 | **思源黑体** (Regular) | 苹方-简 (Regular) |
| 代码 | **JetBrains Mono** | Fira Code |

### 2.4 图标

| 用途 | 图标库 |
|------|--------|
| UI 图标 | Lucide Icons（首选）/ Heroicons |
| 产品图标 | 自制（星爪紫 + 虫族风格） |
| Emoji | 限用于内部文档，对外材料不用 Emoji |

## 三、语言规范

### 3.1 对外语言风格

| 维度 | 是 | 不是 |
|------|-----|------|
| 语气 | 专业、自信、简洁 | 卖萌、夸张、营销味重 |
| 人称 | "我们"、"StarClaw" | "本公司"、"鄙司" |
| 技术 | 精准但不故弄玄虚 | 堆砌术语吓唬客户 |
| 态度 | 平等对话、解决问题 | 居高临下、硬推销售 |

### 3.2 常用表达

| ✅ 推荐 | ❌ 避免 |
|---------|---------|
| "企业 AI 智能体" | "最强 AI 平台" |
| "帮您管好 AI" | "颠覆行业的 AI 解决方案" |
| "开源、透明、可审计" | "遥遥领先" |
| "支持 20+ 主流模型" | "支持所有模型" |
| "私有部署，数据不出网" | "绝对安全" |
| "降低 AI 使用成本" | "AI 白菜价" |

### 3.3 竞品提及规范

| 规则 | 说明 |
|------|------|
| 不贬低竞品 | 只说自己的优势，不攻击对手 |
| 客观对比 | 功能对比用事实，不用主观判断 |
| 点名规则 | 对外材料可提 Dify、飞书 AI 等公开产品名称作对比 |
| 内部代号 | 竞品统称"大龙虾"（OpenClaw）仅用于内部文档；StarClaw 内部昵称"小龙虾" |

## 四、虫族术语对外使用边界

> StarClaw 内部使用星际争霸虫族（Zerg）世界观作为产品架构隐喻。但**对外沟通时需严格控制虫族术语的使用边界**。

### 4.1 术语分级

| 级别 | 说明 | 可用场景 |
|------|------|---------|
| 🟢 **对外可用** | 已成为产品名/品牌名的虫族术语 | 官网、文档、营销 |
| 🟡 **技术圈可用** | 开发者社区能接受的术语 | GitHub、技术博客、开发者大会 |
| 🔴 **仅限内部** | 纯虫族角色扮演术语 | 内部文档、团队沟通 |

### 4.2 术语清单

| 术语 | 含义 | 级别 | 对外替代说法 |
|------|------|:----:|-------------|
| **StarClaw** | 品牌名 | 🟢 | — |
| **Claw** | AI 客户端/节点 | 🟢 | "AI 节点"、"AI 工位" |
| **Overlord** | 企业管理平台 | 🟢 | "企业管控平台" |
| **Queen** | 总控平台 | 🟡 | "管理后台"（对客户不提） |
| **Cerebrate** | 核心合伙人 | 🔴 | "核心合伙人"、"联合创始人" |
| **虫后** | 创始人/CEO | 🔴 | "创始人" |
| **脑虫** | 核心合伙人 | 🔴 | "核心合伙人" |
| **领主** | 城市合伙人 | 🔴 | "城市合伙人" |
| **虫群** | 节点网络 | 🟡 | "分布式 AI 网络" |
| **菌毯 / Creep** | 数据同步层 | 🟡 | "数据同步网络" |
| **进化 / Evolution** | 个体升级 | 🟡 | "自适应优化" |
| **星能** | 算力单位 | 🟢 | — |
| **孵化** | 节点部署 | 🟡 | "一键部署" |
| **Hivemind** | 集群智能 | 🟡 | "分布式协作" |
| **Nydus** | 隧道/穿透 | 🟡 | "安全隧道" |
| **Molt** | 版本升级 | 🟡 | "热更新" |
| **大龙虾** | 竞品代号（OpenClaw） | 🔴 | 使用竞品真实名称 |
| **小龙虾** | StarClaw 内部昵称 | 🔴 | 对外统一用 "StarClaw" |

### 4.3 使用原则

1. **客户面前不玩梗** — 企业客户关心的是"能不能解决我的问题"，不是"你们的世界观多有趣"
2. **开发者社区可以适度** — 技术圈对虫族隐喻接受度高，GitHub README 和技术博客可以用 🟡 级术语
3. **白牌客户绝对不用** — 白牌客户的终端用户不应看到任何虫族相关内容
4. **产品 UI 中不用** — 产品界面使用通用术语（"节点"、"团队"、"模型"），不出现虫族术语
