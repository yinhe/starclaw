# StarClaw 内容营销计划

> 内部文件 — 通过内容建立品牌认知、获取精准线索

---

## 一、内容策略总览

```
目标受众：
  开发者 → 认知 StarClaw → Star / 试用 → 转介绍企业用户
  IT 决策者 → 认知企业 AI 管控需求 → Demo → 签约

内容金字塔：
  顶层（每季度）：行业白皮书 / 年度报告 — 建立权威
  中层（每月）：深度长文 / 案例分析 — 精准获客
  底层（每周）：技术博客 / 短内容 — 持续曝光
```

## 二、内容矩阵

### 2.1 按受众分

| 受众 | 关心什么 | 内容类型 | 渠道 |
|------|---------|---------|------|
| **开发者** | 能不能跑、好不好用、架构牛不牛 | 技术教程、架构解析、对比评测 | GitHub / 掘金 / 知乎 / HN |
| **IT 主管 / CTO** | 安全不安全、合不合规、成本多少 | 行业方案、ROI 分析、案例 | 公众号 / 知乎 / 官网 |
| **企业老板** | 能不能提效、花多少钱 | 客户案例、行业趋势、短视频 | 公众号 / 抖音 / 即刻 |
| **渠道伙伴** | 好不好卖、赚多少钱 | 城市合伙人招募文、收益分析 | 公众号 / 朋友圈 / 行业群 |

### 2.2 按频率分

| 频率 | 内容 | 字数 | 负责人 | 渠道 |
|------|------|:----:|--------|------|
| **每天** | Twitter/X 动态（英文） | 100-280 字 | 创始人 | Twitter |
| **每天** | 朋友圈/即刻短内容 | 50-200 字 | 核心合伙人（运营） | 微信/即刻 |
| **每周** | 技术博客 | 1,500-3,000 字 | 核心合伙人（技术） | 掘金/知乎/公众号 |

## 六、Webinar 运营

### 标准 Webinar 流程

```
时间：每月第 3 个周三 14:00-15:00
平台：腾讯会议（国内）/ Zoom（国际）

议程：
  14:00-14:05  开场介绍
  14:05-14:20  主题分享（行业趋势/产品功能/最佳实践）
  14:20-14:40  Live Demo
  14:40-14:55  Q&A
  14:55-15:00  下一步（试用/Demo 预约/资料下载）

会后：
  - 24 小时内发送录屏 + PPT
  - 筛选高意向参与者（提问多、留了联系方式）
  - 3 天内销售跟进
```

## 七、内容分发矩阵

每篇内容不是发一个平台，而是**一鱼多吃**：

```
一篇深度长文 →
  ├── 公众号全文
  ├── 知乎回答（改写为问答格式）
  ├── 掘金/CSDN（技术向改写）
  ├── Twitter 线程（英文摘要 5-8 条）
  ├── 朋友圈/即刻（金句 + 链接）
  ├── 视频脚本（5 分钟讲解版）
  └── 社群讨论话题
```
