## 一、客户画像

### 1.1 理想客户画像（ICP）

| 维度 | 描述 |
|------|------|
| 规模 | 50-1000 人 |
| 行业 | 制造、教育、法律、金融、电商、医疗、IT 服务 |
| 痛点 | 员工已在用 ChatGPT 但无法管控/审计/安全 |
| 预算 | IT 预算 ¥5,000-50,000/月，有 AI 降本增效需求 |
| 决策人 | CTO / IT 主管 / 运营总监 |
| 信号 | 已在用 AI 工具、关注数据安全、有合规要求 |

### 1.2 客户分层

| 层级 | 人数 | 目标套餐 | ARPU | 成交周期 | 决策模式 |
|------|:----:|---------|:----:|:--------:|---------|
| S 级 | 500+ | Enterprise / White-Label | ¥5,000-30,000/月 | 1-3 月 | 委员会决策 |
| A 级 | 100-500 | Pro / Enterprise | ¥2,000-5,000/月 | 2-4 周 | CTO 决策 |
| B 级 | 50-100 | Pro | ¥1,999/月 | 1-2 周 | IT 主管决策 |
| C 级 | 10-50 | Starter | ¥499/月 | 3-7 天 | 老板直接拍板 |

> **主攻 A/B 级客户** — 成交快、ARPU 合理、续费率高。S 级客户战线长但 LTV 大，有机会就跟。

### 1.3 行业切入优先级

| 优先级 | 行业 | 理由 | 切入话术 |
|:------:|------|------|---------|
| ⭐⭐⭐ | **制造业** | 合规需求强、IT 预算充裕、数据敏感 | "你的工程师把图纸贴给了 ChatGPT" |
| ⭐⭐⭐ | **教育** | AI 需求爆发、政策鼓励、采购决策快 | "给每个老师一个 AI 备课助手" |
| ⭐⭐⭐ | **法律** | 高度数据敏感、AI 文书刚需、付费能力强 | "合同审查从 3 天变 3 小时" |
| ⭐⭐ | **金融** | 合规审计刚需、但采购流程长 | "满足银保监审计要求的 AI 平台" |
| ⭐⭐ | **电商** | AI 文案/客服需求大、决策快 | "AI 批量生成商品文案" |
| ⭐ | **医疗** | 数据极敏感、采购周期极长 | 长线培育，不做主攻 |

## 二、销售流程

### 2.1 标准销售流程（BANT + Demo）

```
获客 → 需求确认 → Demo 演示 → 方案报价 → 异议处理 → 签约 → 交付
 │       │           │          │           │          │       │
 │    电话/微信     30分钟      定制报价    解决顾虑    合同     delivery-sop
 │    确认BANT     远程/上门    邮件/微信   当面/电话   电子签    
 │                                                             
 D1      D1-D3       D3-D7      D7-D10     D10-D14    D14     D15-D28
```

### 2.2 BANT 快速判断

在第一次沟通中确认以下四点，决定是否值得跟进：

| 维度 | 问什么 | 合格标准 |
|------|--------|---------|
| **B**udget（预算） | "贵司目前 AI 相关的月度开支大概多少？" | ≥ ¥2,000/月 或明确有预算 |
| **A**uthority（决策人） | "这个事情谁来拍板？" | 能见到 CTO/IT 主管/老板 |
| **N**eed（需求） | "目前员工是怎么用 AI 的？遇到什么问题？" | 有明确痛点（安全/管控/成本） |
| **T**imeline（时间） | "大概什么时候想上线？" | 3 个月内 |

> 4 项中满足 3 项 = 值得跟进。只满足 1-2 项 = 放入培育池，定期触达。

### 2.3 Demo 演示流程（30 分钟）

```
时间分配：
  0-5 分钟    破冰 + 了解客户现状
  5-10 分钟   痛点共鸣（"你的员工已经在偷偷用 ChatGPT"）
  10-20 分钟  产品演示（3 个核心场景）
  20-25 分钟  套餐介绍 + 报价
  25-30 分钟  Q&A + 下一步
```

**Demo 三板斧（按顺序演示）：**

| 顺序 | 演示什么 | 为什么先演示这个 | 话术 |
|:----:|---------|---------------|------|
| ① | **团队隔离 + 模型路由** | 直击管控痛点 | "研发用 DeepSeek 写代码，市场用 GPT-4o 写文案，互不可见" |
| ② | **知识库 + Agent** | 展示业务价值 | "上传公司手册，AI 自动回答新员工问题" |
| ③ | **用量审计仪表盘** | 成本透明 = 决策人关心的 | "每个部门花了多少钱、用了什么模型，一目了然" |

**Demo 环境准备：**
- 提前创建 3 个团队（研发/市场/HR），配置不同模型
- 上传一份通用知识库文档（如公司制度手册模板）
- 确保用量仪表盘有模拟数据

### 2.4 报价策略

| 客户类型 | 推荐套餐 | 报价策略 |
|---------|---------|---------|
| C 级（10-50 人） | Starter ¥499/月 | 直接报价，不谈折扣 |
| B 级（50-100 人） | Pro ¥1,999/月 | 推年付 ¥1,599/月（8 折），强调省 ¥4,800 |
| A 级（100-500 人） | Pro 或 Enterprise | 先报 Enterprise ¥4,999，客户嫌贵再推 Pro |
| S 级（500+） | Enterprise / White-Label | 定制方案，面议 |

**定价底线（核心合伙人/城市合伙人谈判红线）：**

| 套餐 | 官网价 | 最低折扣 | 底线价 | 审批 |
|------|:------:|:-------:|:------:|------|
| Starter | ¥499/月 | 不打折 | ¥499 | — |
| Pro | ¥1,999/月 | 年付 8 折 | ¥1,599/月 | — |
| Enterprise | ¥4,999/月 | 年付 8 折 | ¥3,999/月 | — |
| 特殊折扣 | — | 7 折 | — | 需平台审批 |

> **铁律：月付不打折，折扣只给年付。** 客户要折扣 → 引导签年约。
> 3 年合同可谈 7 折，需平台审批。

## 三、异议处理

### 3.1 价格异议

| 客户说 | 怎么回 |
|--------|--------|
| "太贵了" | "Pro ¥1,999/月 ÷ 100 节点 = ¥20/节点。飞书 AI 要 ¥30/人/月，而且不能私有部署。" |
| "Dify 是免费的" | "Dify 是开发工具，没有团队管理、SSO、审计。你需要的不是 AI 能力，是管得住的 AI 平台。" |
| "能不能先免费试" | "可以，Community 版 5 节点免费，够你 5 个人先试。用着好再升级。" |
| "能不能打折" | "月付不打折。签年约 8 折，省 ¥4,800。我帮你算一下年付更划算。" |
| "预算还没批" | "理解。我们有免费 Community 版，可以先部署试用，拿到实际效果数据帮你推预算。" |

### 3.2 安全异议

| 客户说 | 怎么回 |
|--------|--------|
| "数据安全怎么保证" | "私有部署在你的内网，数据不出你的服务器。用国产模型（DeepSeek/Qwen）可以零数据出境。" |
| "开源是不是不安全" | "相反，开源更安全。代码公开可审计，你的安全团队可以逐行检查。闭源产品你反而不知道它干了什么。" |
| "用海外模型有合规风险" | "支持纯国产模型本地部署，满足《数据安全法》要求。海外模型是可选项，不是必须。" |

### 3.3 功能异议

| 客户说 | 怎么回 |
|--------|--------|
| "我们只需要 ChatGPT" | "ChatGPT 你管不了——谁用了、用多少、传了什么数据你都不知道。StarClaw 让你管得住。" |
| "功能够不够多" | "20+ 模型、Agent 编排、知识库、工具调用、工作流——Dify 有的我们都有，我们还多了企业管控。" |
| "能不能对接我们的系统" | "支持 API 对接 + MCP 工具协议 + Webhook。Enterprise 版含定制开发额度。" |
| "我们已经在用 XX 了" | "不冲突。StarClaw 支持多模型统一接入，可以把你现有的 AI 工具整合到一个可管控的平台里。" |

### 3.4 信任异议

| 客户说 | 怎么回 |
|--------|--------|
| "你们公司太小了" | "我们核心代码开源。就算公司不在了，你的平台还能继续跑。闭源产品倒了你就全停了。" |
| "没听说过你们" | "我们刚起步，所以价格有竞争力。等我们成了行业标准，价格就不是这个了。现在签约锁价最划算。" |
| "能不能看看案例" | "（有案例时）这是 XX 行业客户的使用效果。（无案例时）你可以成为我们的标杆客户，额外享受 XX 权益。" |

## 四、客户获取渠道

### 4.1 城市合伙人获客方法

| 渠道 | 方法 | 预期转化率 | 成本 |
|------|------|:---------:|------|
| **存量关系** | 朋友圈/微信群发产品海报 | 5-10% 约演示 | ¥0 |
| **行业活动** | 参加本地 IT/AI/行业展会 | 3-5% 留联系方式 | ¥500-2,000/场 |
| **企业拜访** | 扫楼/陌拜 IT 部门 | 1-3% 约演示 | ¥0（时间成本） |
| **转介绍** | 老客户推荐新客户 | 20-30% 成交 | ¥0（可给老客户返佣） |
| **线上内容** | 知乎/公众号/抖音发 AI 科普 | 1-2% 留联系方式 | ¥0（时间成本） |

> **最高效的渠道：转介绍 > 存量关系 > 行业活动 > 线上内容 > 陌拜**

### 4.2 核心合伙人获客方法

核心合伙人除以上所有渠道外，还可以：

| 渠道 | 方法 |
|------|------|
| GitHub/开源社区 | 技术博客引流 → Demo → 转企业客户 |
| 战略合作 | 与 IT 服务商/系统集成商/云厂商合作 |
| 行业白皮书 | 发布行业 AI 应用报告，获取精准线索 |
| 线上研讨会 | 每月一场 AI 应用 Webinar |

## 七、销售纪律

| 规则 | 说明 |
|------|------|
| **24 小时响应** | 客户咨询 24 小时内必须回复 |
| **不承诺做不到的** | 不存在的功能不能说"有"，说"在规划中" |
| **不诋毁竞品** | 只说自己的优势，不攻击 Dify/飞书/百度 |
| **不低于底价** | 月付不打折，年付最低 8 折，特殊折扣需审批 |
| **客户信息保密** | 客户资料不外传，不在公开场合讨论具体客户 |
| **每周更新管道** | Partner Hub CRM 每周更新客户状态 |
| **签约走平台** | 所有合同通过平台签署，不私下收款 |
