## 可定制项

### 🎨 品牌层（100% 可替换）

| 元素 | 说明 | 示例 |
|------|------|------|
| 品牌名 | 产品名称 | "智脑AI" / "DataMind" / "星途助手" |
| Logo | 主 Logo + Favicon | 你的设计稿，我们适配 |
| 色调 | 主色 + 辅色 + 背景 | `#FF6B00` 橙色系 |
| 域名 | 独立域名 + SSL | ai.your-brand.com |
| 登录页 | 自定义背景/文案/布局 | 你的品牌 Landing Page |
| 邮件模板 | 注册/重置/通知邮件 | 发件人: noreply@your-brand.com |
| 版权信息 | 页脚版权文字 | © 2026 Your Company |
| 备案号 | 国内备案信息 | 粤ICP备XXXXXXX号 |

### 🧬 功能层（按需开关）

| 模块 | 可开关 | 说明 |
|------|:-----:|------|
| AI 对话 | ✅ | 核心功能，通常必开 |
| Agent 模板市场 | ✅ | 可自建模板 + 从 StarClaw 生态同步 |
| 知识库 | ✅ | 企业文档上传和问答 |
| 图片生成 | ✅ | DALL-E / FLUX |
| 视频生成 | ✅ | 高成本模块，可关闭 |
| 工具调用 | ✅ | 飞书/钉钉/企微等集成 |
| 算力市场 | ✅ | P2P 算力交易（通常 B 端关闭） |
| 社区功能 | ✅ | 用户论坛/分享 |
| 企业 SSO | ✅ | LDAP/SAML/OAuth |
| 审计日志 | ✅ | 合规需求 |
| 用量计费 | ✅ | 面向终端用户的计费（或由企业统一买单） |

### 🏗️ 架构层（可选）

| 选项 | 标准 | 高级 |
|------|------|------|
| 部署方式 | SaaS 共享 | 独立实例/私有部署 |
| 数据库 | 共享 MySQL（逻辑隔离） | 独立 MySQL |
| 模型接入 | 平台统一（20+ 模型） | 自有模型 API 接入 |
| 存储 | 平台 OSS | 客户自有 OSS/S3 |
| CDN | 平台统一 | 客户自有 CDN |
