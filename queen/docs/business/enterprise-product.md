## 核心能力

### 🔒 数据安全 — 私有部署

```
┌─────────────────────────────┐
│     你的企业内网 / 私有云      │
│                              │
│   ┌────────────────────┐    │
│   │  StarClaw 企业版    │    │  ← 部署在你的环境里
│   │                    │    │
│   │  员工的对话 → 留在这里 │    │  ← 数据不出内网
│   │  模型调用 → 加密通道  │    │  ← 只有指令出去
│   └────────────────────┘    │
│                              │
└─────────────────────────────┘
```

- 所有对话数据存储在你的服务器
- 模型调用通过加密通道，只传 prompt，不传业务数据
- 支持国产模型（DeepSeek / Qwen）完全本地运行，零数据外传

### 👥 团队管理 — 按部门隔离

| 能力 | 说明 |
|------|------|
| 团队隔离 | 研发、市场、HR 各用各的，互不可见 |
| 模型路由 | 研发用 DeepSeek-Coder，市场用 GPT-4o，HR 用 Qwen |
| 配额管控 | 每个团队每月 Token 上限，超额自动暂停 |
| SSO 直登 | 对接企业 AD/LDAP/飞书/钉钉，员工无需额外注册 |
