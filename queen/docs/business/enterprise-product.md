## 核心能力

### 🔒 数据安全 — 私有部署

```
┌─────────────────────────────┐
│     你的企业内网 / 私有云      │
│                              │
│   ┌────────────────────┐    │
│   │  StarClaw 企业版    │    │  ← 部署在你的环境里
│   │                    │    │
│   │  员工的对话 → 留在这里 │    │  ← 数据不出内网
│   │  模型调用 → 加密通道  │    │  ← 只有指令出去
│   └────────────────────┘    │
│                              │
└─────────────────────────────┘
```

- 所有对话数据存储在你的服务器
- 使用海外模型（GPT-4o/Claude）时，prompt 会经加密通道发送至模型服务商，请根据企业数据合规要求选择合适的模型
- 支持国产模型（DeepSeek / Qwen）完全本地部署，**零数据出境**，满足《数据安全法》及《个人信息保护法》要求
- 对数据安全要求严格的行业（金融/医疗/政务），建议使用国产模型本地部署方案

### 👥 团队管理 — 按部门隔离

| 能力 | 说明 |
|------|------|
| 团队隔离 | 研发、市场、HR 各用各的，互不可见 |
| 模型路由 | 研发用 DeepSeek-Coder，市场用 GPT-4o，HR 用 Qwen |
| 配额管控 | 每个团队每月 Token 上限，超额自动暂停 |
| SSO 直登 | 对接企业 AD/LDAP/飞书/钉钉，员工无需额外注册 |
