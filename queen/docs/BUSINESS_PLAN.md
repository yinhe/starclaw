## 一、执行摘要

### 1.1 一句话定位

**StarClaw（星爪）是一个开源 AI Agent 编排平台，通过"开源核心 + 商业增值"的双轨模式，构建全球分布式智能体网络。**

### 1.2 核心价值主张

- **对个人用户：** 一行命令部署私有 AI 助手，多模型统一接入，BYOK 完全免费
- **对企业客户：** 私有化部署 + 企业级管控（Overlord），多租户 RBAC，OTA 更新，审计合规
- **对开发者：** 开源引擎 + MCP 兼容 + 可视化工作流 + Plugin 生态，低门槛构建 AI 应用
- **对生态参与者：** Agent/Plugin 市场变现 + 赏金系统收入 + 算力提供商合作分成

### 1.3 商业亮点

| 维度 | 亮点 |
|------|------|
| **技术壁垒** | 自研虫群架构（Queen→Overlord→Claw）+ Ed25519 加密身份 + P2P Gossip + DHT |
| **网络效应** | 越多 Claw 加入 → 网络越强 → 知识越丰富 → 吸引更多节点 |
| **收入多元** | 五大收入源：算力抽成、企业订阅、市场分成、赏金抽成、托管服务 |
| **全栈覆盖** | IoT（8MB）→ 手机（64MB）→ PC（256MB）→ GPU 服务器（4GB+）→ 机器人 |
| **开源护城河** | 核心引擎完全开源，闭源增值层提供商业化空间 |

## 二、公司与产品概述

### 2.1 项目背景

AI Agent 正从实验室走向生产环境，但行业面临三大痛点：

1. **碎片化严重** — 模型厂商各自为政，开发者需对接多家 API
2. **部署门槛高** — 现有 Agent 框架配置复杂，非技术用户无法使用
3. **数据安全焦虑** — 企业不愿将敏感数据上传至第三方 SaaS

StarClaw 以**开源自部署**解决安全问题，以**多模型统一接入**解决碎片化，以**一行命令部署**解决门槛。

### 2.2 命名与品牌

| Queen（虫后） | 中央管控平台 | 全网唯一，统一管理 |
| Overlord（领主） | 企业管理层 | 付费产品，管辖 Brood |
| Claw（小龙虾） | 最小执行单元 | 开源核心，独立部署 |
| Swarm（虫群） | 全网节点网络 | 所有注册节点 |
| Molt（蜕皮） | OTA 自动更新 | 全网版本统一 |
| Nydus（坑道虫） | P2P 互联层 | 节点间加密直连 |

### 3.2 目标用户

| 用户群体 | 需求痛点 | StarClaw 价值 | 付费意愿 |
|---------|---------|-------------|---------|
| **独立开发者** | 快速构建 AI 应用 | 开源免费 + BYOK | 低（star-ai.net 小额） |
| **AI 爱好者** | 探索 Agent 玩法 | 一键部署 + 社区 | 低（社区活跃度） |

3. **多模型混用** — 没有单一模型适合所有任务
4. **AI Agent 标准化** — MCP 等标准协议统一生态
5. **边缘 AI** — 小模型 + 端侧推理 + IoT 快速增长
6. **AI 原生应用** — Agent 作为新的应用形态

| **Overlord 全功能** | 100% | 管控 + RBAC + 隧道 + Molt + Webhook + 控制台 |
| **Queen Swarm** | 80% | 注册/心跳/解析 ✅，负载均衡 ❌ |
| **Queen Billing** | 60% | 充值/扣费/支付 ✅，冻结/释放 ❌ |
| **社区三件套** | 60% | Bounty/Forum/Arena 后端 ✅，前端 ❌ |
| **Flutter 客户端** | 40% | 8 屏框架 ✅，功能完善 ❌ |

### 4.2 核心技术壁垒

**壁垒一：虫群三级架构** — 业界首创 Queen→Overlord→Claw 分布式 AI Agent 管控架构，网络效应 + 生态锁定形成正反馈飞轮。

**壁垒二：加密身份 + P2P** — Ed25519 密钥对派生 `claw:` 地址，Gossip + DHT + NAT 穿透实现去中心化节点发现与直连。竞品需同时掌握密码学、分布式系统、网络协议才能复制。

**壁垒三：Feral 失控模式** — Queen 宕机后所有 Claw 本地功能完全正常，DHT 保证节点间仍可发现。真正的"去中心化 AI Agent 网络"。

**壁垒四：5 种体型全覆盖** — 从 IoT 传感器（8MB Larva）到 GPU 服务器（4GB+ Ultralisk）到机器人（Mutalisk），竞品仅支持服务器部署。

### 4.3 数据隐私

**核心原则：用户数据留在本地 Claw，不上传。** 天然符合 GDPR / 中国《数据安全法》，是企业私有化部署首选。
