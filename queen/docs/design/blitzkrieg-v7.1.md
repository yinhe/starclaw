```

## 一、100% 消费利润分配

> 消费利润 = 用户支付 - 上游模型成本（约23%利润率，即1.3x加价）

### 1.1 有城市合伙人归属的消费

| 层级 | 比例 | 说明 |
|------|:---:|------|
| 🟢 **城市佣金** | **20-30%** | 阶梯制，用业绩升级（不用花钱） |
| 🟡 **增长奖金** | **0-5%** | 里程碑 + 月度竞赛 + 年度忠诚 |
| 🔵 **团队共享** | **10%** | 36席按贡献分配，不递减 |
| 🟣 **NAV注入** | **10%** | 只进不出，推高星钻净值 |
| ⚪ **平台留存** | **47-62%** | 运营/研发/获客/储备 |

### 1.2 无城市合伙人归属的消费

| 层级 | 比例 |
|------|:---:|
| 🔵 团队共享 | 10% |
| 🟣 NAV注入 | 10% |
| ⚪ 平台留存 | **80%** |

| 场景 | 城市佣金 | 增长奖金 | 团队共享 | NAV注入 | 平台留存 |

## 二、城市合伙人佣金阶梯

### 2.1 阶梯规则

| 等级 | 活跃用户数 | 佣金率 | 升级感 |
|:---:|:--------:|:-----:|-------|
| 🥉 入门 | 0-9 | **20%** | "先干起来" |
| 🥈 白银 | 10-49 | **25%** | "再拉几个就升级" |
| 🥇 黄金 | 50-99 | **28%** | "快到钻石了" |
| 💎 钻石 | 100+ | **30%** | "我是最高级" |

### 2.2 规则细节

```
活跃用户定义：
  过去30天内有过至少1次AI消费的归属用户

阶梯判定：
  每月1日根据上月活跃用户数重新判定等级
  等级可升可降（驱动持续努力）
  
例外 — 年度忠诚锁定：
  连续12个月活跃的合伙人 → 等级永久锁定（只升不降）
  防止老合伙人因用户自然流失而降级
```

### 2.3 与旧版对比

```
v5.0/v6.0：花钱买佣金率
  "投¥5万 → 佣金从10%升到15%"
  感觉 = 充值游戏，被割韭菜

v7.1：用业绩赚佣金率
  "拉到10个活跃用户 → 佣金从20%升到25%"
  感觉 = 打怪升级，成就感

同样是20%→30%的区间，驱动力完全不同。
```

### 2.4 30秒话术

```
"你帮我推广AI工具，起步佣金20%。
 拉到10个用户升到25%，50个升到28%，100个到顶30%。

## 三、增长奖金体系

两套奖金，两个资金池，两种驱动逻辑：

```
城市合伙人奖金 → 驱动拉用户 → 资金来源：消费利润的0-5%
团队合伙人奖金 → 驱动拉合伙人+拉资源 → 资金来源：星钻启动金（¥350万）
```

### 3.1 城市合伙人增长奖金（从消费利润0-5%出）

**① 里程碑奖（一次性，驱动破冰和冲关）**

| 里程碑 | 条件 | 奖金 | 人性杠杆 |
|-------|------|:----:|---------|
| 🎯 首单 | 第1个活跃用户 | ¥100 | 即时反馈，破冰 |
| 🔟 十人 | 累计10个活跃用户 | ¥500 | "差2个就到了" |
| 🏅 五十人 | 累计50个活跃用户 | ¥3,000 | 中级里程碑 |
| 🏆 百人 | 累计100个活跃用户 | ¥10,000 | 大奖驱动冲刺 |

**② 月度竞赛（持续性，驱动每月活跃）**

```
月度排行榜（合伙人后台首页展示）：
  🏆 本月Top 10城市合伙人
  #1  杭州-王**  ¥12,350  新增用户 47
  #2  深圳-李**  ¥8,720   新增用户 31
  ...

Top 3 瓜分月度奖金池
当月新增用户增长率 > 20% → 当月佣金额外+3%
```

**③ 年度忠诚（长期性，防止流失）**

```
连续活跃12个月 → 佣金阶梯永久锁定（只升不降）
连续活跃24个月 → "创始合伙人"称号 + 优先认购下一轮星钻
```

### 3.2 团队合伙人增长奖金（从星钻启动金出，不占消费利润）

> 团队拉的是合伙人和战略资源，不直接产生消费，所以不从消费利润出，从启动金出。

| 奖金 | 条件 | 金额 | 驱动行为 |
|------|------|:----:|---------|
| 🤝 裂变奖 | 推荐1个新城市合伙人签约 | ¥1,000 | 渠道网络扩张 |
| 🏢 大客户奖 | 引入1个企业客户（月消费≥¥5万） | ¥5,000 | 高价值客户 |
| 🎯 战略奖 | 促成1个战略合作落地（甲方认可） | ¥10,000 | 资源引入 |
| 🌐 网络奖 | 下辖活跃城市合伙人达到10个 | ¥20,000 | 渠道管理 |

```
启动金预算分配（¥350万中拨¥100万给增长奖金池）：
  城市里程碑奖：¥40万（约100个百人奖 or 400个十人奖）
  团队增长奖：  ¥40万（约40个裂变奖 + 大客户奖 + 战略奖）
  月度竞赛池：  ¥20万（约20个月的月度Top 3奖金）
```

### 3.3 人性原理

```
城市合伙人：
  里程碑 → 游戏化（"还差3个到下一关"）
  排行榜 → 攀比心（"他赚了¥12,350，我才¥3,000？"）
  忠诚锁 → 沉没成本（"再坚持2个月就永久锁定了"）

团队合伙人：
  裂变奖 → 即时回报（"介绍一个人就拿¥1,000"）
  大客户奖 → 结果导向（"签下一个大客户奖¥5,000"）
  网络奖 → 长期目标（"建起10人渠道网络奖¥20,000"）

关键区别：
  城市 = 高频小额，驱动日常推广行为
  团队 = 低频大额，驱动战略级动作
```

## 四、团队共享利润（10%）

### 4.1 分配规则

```
团队共享池 = 每笔消费利润 × 10%（每笔都注入，无论有无城市归属）

月度分配 = 团队共享池 × (个人贡献系数 / Σ全部贡献系数)

贡献系数由甲方根据以下因素评定：
  (a) 业绩里程碑完成情况
  (b) 当期实际业务贡献（可量化成果）
  (c) 角色标签对应的核心职责履行情况
```

### 4.2 关键设计决策

```
✅ 不递减：10%固定，蛋糕变大绝对金额增长
✅ 不区分投资：投不投星钻，权重一样（公平）
✅ 按贡献不按人头：有异议可走争议解决条款

❌ 不搞×1.5权重：团队用贡献说话，不用钱说话
```

### 4.3 演算

```
36席，月利润 ¥500万：
  团队共享池 = ¥500万 × 10% = ¥500,000
  平均每席 = ¥500,000 / 36 ≈ ¥13,889/月
  
月利润 ¥5,000万：
  团队共享池 = ¥5,000万 × 10% = ¥5,000,000
  平均每席 ≈ ¥138,889/月

不递减的动力：团队知道蛋糕越大自己拿越多 → 拼命做大蛋糕。
```

## 五、星钻体系（极简版）

### 5.1 定位

```
星钻 = 入伙押金 + 平台增值凭证
星钻 ≠ 理财产品（无月度分红）

星钻的价值 = 退出时NAV × 持有份数
NAV只涨不分 → 像买房，不收月租，但房价在涨
```

### 5.2 NAV模型

```
NAV = (星钻投资总额 + 累计10%利润注入 - 累计退出支付) / 已发行星钻总数

关键：10%利润注入只进不出，无月度分红 → NAV纯累积增长

只在两个时点计算NAV：
  ① 新一轮星钻发行定价时
  ② 合伙人退出结算时
```

### 5.3 星钻对两类合伙人的价值

| | 城市合伙人 | 团队合伙人 |
|---|-----------|-----------|
| **投资额** | ¥5万 | ¥10万 |
| **核心价值** | 客户归属**永久化** | 退出时**NAV增值** |
| **不投资** | 归属跟协议走（3年） | 纯拿团队共享+股权 |
| **NAV增值** | ✅ | ✅ |
| **影响佣金率？** | ❌（佣金靠业绩升级） | ❌（无佣金概念） |
| **影响团队分配？** | — | ❌（纯按贡献） |
| **一句话卖点** | "投了，客户永远是你的" | "投了，平台涨你也涨" |

### 5.4 NAV增长演算

```
初始：50人投共¥350万，发行100万份星钻，NAV = ¥3.5/份

              月利润    年注入(10%)   累计注入    NAV       增长率
  买入时       —        —            ¥0         ¥3.5      —
  第1年末     ¥50万     ¥60万        ¥60万      ¥4.1      +17%
  第2年末     ¥200万    ¥240万       ¥300万     ¥6.5      +86%
  第3年末     ¥500万    ¥600万       ¥900万     ¥12.5     +257%
  第5年末     ¥5000万   ¥6000万      ¥1.2亿    ¥123.5    +3429%

城市合伙人投¥5万（25,000份）：
  第3年市值 = 25,000 × ¥12.5 = ¥312,500（6.25倍）
  
团队合伙人投¥10万（50,000份）：
  第3年市值 = 50,000 × ¥12.5 = ¥625,000（6.25倍）
```

### 5.5 星钻资金用途

```
孢子期预期募集：30城市×¥5万 + 20团队×¥10万 = ¥350万

分配：
  ¥100万 → 服务器/模型API（12个月运营）
  ¥100万 → 增长奖金池（里程碑奖励预算）
  ¥50万  → 基础运营费用
  ¥100万 → 储备金

这笔钱不做月度分红 = 不会被持续抽走
只在合伙人退出时按NAV结算
```

### 5.6 后续轮次

```
甲方可根据平台发展需要分轮次发行星钻。
后续轮次发行价格 ≥ 当前NAV（不低于净值发行）。
每轮具体参数由甲方另行公布。

早投优势：
  孢子期 NAV ¥3.5 → 投¥5万得25,000份
  后续轮 NAV ¥12.5 → 投¥5万只得4,000份
  早投6倍份数优势
```

## 七、锁定机制（不花钱但走不掉）

```
城市合伙人在StarClaw积累的不可转移资产：

  ① 客户归属 → 147个用户在这里，走了就没了
  ② 佣金阶梯 → 花6个月升到黄金28%，换平台从0开始
  ③ 累计数据 → 推广记录、转化率、排名
  ④ 合伙人身份 → "StarClaw杭州城市合伙人"印在名片上
  ⑤ 年度忠诚锁定 → 再2个月就永久锁定了，现在走？
  ⑥ 星钻（如已投资）→ ¥5万在里面，NAV在涨，退出要折价

  任何一项都不是"投入的钱"，而是"积累的资产"。
  积累越多，切换成本越高。
```
