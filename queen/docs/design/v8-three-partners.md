## 〇、核心理念

```
找对的人做对的事，给对的回报。

  卖的人 → 给佣金（即时现金）
  干的人 → 给期权（长期增值）
  出钱的人 → 给利润分成（投资回报）

  不让一个人扮演两个角色。
  不让销售员当投资人。
  不让创始人靠月度分红活着。
```

## 一、100% 消费利润分配

> 消费利润 = 用户支付 - 上游模型成本（约23%利润率）

### 1.1 分配架构

| 层级 | 比例 | 接收方 | 说明 |
|------|:---:|--------|------|
| 🟢 **城市佣金** | **20-30%** | 城市合伙人 | 业绩阶梯，零投资 |
| 🟡 **增长奖金** | **0-5%** | 城市+团队 | 里程碑/月赛/裂变 |
| � **团队共享** | **10%** | 团队合伙人 | 36席按贡献分配，不要求投资 |
| � **星钻利润池** | **10%** | 投资合伙人(LP) | 按出资比例分配 |
| ⚪ **平台运营** | **45-60%** | 平台 | 运营/研发/增长 |

### 1.2 场景矩阵

| 场景 | 城市佣金 | 增长奖金 | 团队共享 | 星钻池 | 平台 |
|------|:------:|:------:|:------:|:-----:|:---:|
| 💎 钻石城市(100+用户) | 30% | 2% | 10% | 10% | **48%** |

| 🥉 入门城市(0-9用户) | 20% | 5% | 10% | 10% | **55%** |
| 无城市归属 | — | — | 10% | 10% | **80%** |

> 加权平均（30%消费有归属，平均佣金25%）：平台实际留存 ≈ **69%**
> 团队共享和星钻池每笔消费都注入（无论有无城市归属）

## 二、三类合伙人

### 2.1 城市合伙人 — 卖

```
角色：渠道销售
贡献：用户和客户
回报：佣金 20-30%（业绩阶梯）+ 增长奖金
出钱：不需要
协议：城市合伙人合作协议
人数：72席
```

**佣金阶梯：**

| 等级 | 活跃用户数 | 佣金率 |
|:---:|:--------:|:-----:|
| 🥉 入门 | 0-9 | **20%** |
| 🥈 白银 | 10-49 | **25%** |
| 🥇 黄金 | 50-99 | **28%** |
| 💎 钻石 | 100+ | **30%** |

- 12个月连续活跃 → 阶梯永久锁定
- 零投资，纯靠业绩升级

**增长奖金（城市）：**

| 奖金 | 条件 | 金额 |
|------|------|:----:|
| 首单奖 | 第1个活跃用户 | ¥100 |
| 十人奖 | 累计10个 | ¥500 |
| 五十人奖 | 累计50个 | ¥3,000 |
| 百人奖 | 累计100个 | ¥10,000 |

**30秒话术：**
```
"帮我推广AI工具，佣金20%起步。
 拉到10个用户升25%，50个升28%，100个到顶30%。
 不用投钱，用业绩说话。"
```

### 2.2 团队合伙人 — 干

```
角色：核心合伙人
贡献：时间、能力、资源
回报：10%利润共享（按贡献分配）+ 增长奖金
出钱：不需要
协议：团队合伙人合作协议
人数：36席
```

**利润共享规则：**
```
团队共享池 = 每笔消费利润 × 10%（每笔都注入，无论有无城市归属）
月度按贡献系数分配，36席共享
不要求投资，不出钱也有

月利润¥500万时：每席 ≈ ¥13,889/月
月利润¥5000万时：每席 ≈ ¥138,889/月
```

**增长奖金（团队）：**

| 奖金 | 条件 | 金额 |
|------|------|:----:|
| 裂变奖 | 推荐1个新城市合伙人签约 | ¥1,000 |
| 大客户奖 | 引入企业客户(月消费≥¥5万) | ¥5,000 |
| 战略奖 | 促成战略合作落地 | ¥10,000 |
| 网络奖 | 下辖10个活跃城市合伙人 | ¥20,000 |

**对外话术：**
```
"平台利润的10%永远分给36个核心合伙人，按贡献分。
 不需要出钱，平台赚钱你就赚钱。"
```

### 2.2.1 核心股权（另签，不在团队合伙人协议中）

```
群星模式 1+5+30 = 51%（公司层面股权，独立于利润共享）

  虫后 Queen      1人 × 6%  =  6%   创始人
  脑虫 Cerebrate  5人 × 3%  = 15%   联合创始人
  领主 Overlord  30人 × 1%  = 30%   核心合伙人

对外口径：1%-3%（不提虫后6%）

股权性质：实缴，可延期
  → 需要实际出资购买股权（不是白送）
  → 但可以延期缴纳（分期/从利润共享中扣除/IPO前补齐）
  → 另签《股权认购协议》，不在团队合伙人合作协议中体现

为什么分开签：
  ① 团队协议 = 利润共享（36人都签，人人有份）
  ② 股权协议 = 实缴股权（另签，金额和时间单独谈）
  ③ 不让"利润共享"和"股权"混在一起 → 各自清晰
  
延期缴纳方式（灵活）：
  方案A：从每月利润共享中按比例扣除 → "用赚到的钱买股权"
  方案B：约定在某一轮融资前补齐
  方案C：IPO前统一行权缴纳
```

### 2.3 投资合伙人 — 出钱

```
角色：资方（LP）
贡献：资金
回报：合伙企业股权 + 星钻利润池10%分成
出钱：是（¥10万-¥1000万/人，视轮次）
协议：有限合伙协议
人数：累计8-40人（合伙企业法上限49个LP）
```

**有限合伙企业结构：**
```
StarClaw 星爪投资合伙企业（有限合伙）

  GP（普通合伙人）：StarClaw 平台公司
    → 执行事务，不出资或象征性出资
    → 承担无限责任
    
  LP（有限合伙人）：投资合伙人
    → 享受10%消费利润分成（按星钻比例）
    → 享有合伙企业股权（LP份额增值）
    → 不参与经营管理
    → 以出资额为限承担责任
```

**星钻 = LP出资凭证：**
```
LP出资 → 按当轮星钻价格获得星钻份额
星钻NAV = 合伙企业净资产 / 已发行星钻总数
利润分成按星钻持有比例分配
保留星钻概念（虫族IP），底层用有限合伙承接
```

**创始LP特权：**

```
  ✅ 创始LP称号（永久）

  ✅ 后续轮次优先追加投资权
```

**分配机制：**
```
第1-12个月（累积期）：
  10%消费利润注入星钻池 → 不分配 → 全部推NAV
  LP后台看到NAV从¥1涨到¥2+ → "我的投资在增值"
  
第13个月起（分红期）：
  10%消费利润注入星钻池
  → 70%季度分配给LP（现金流）
  → 30%留存推NAV（持续增值）

为什么前12个月不分？
  ① 早期利润小 → 分出来每人几百块 → 没体感
  ② 全部累积 → NAV涨得快 → 投资人看着数字涨 → 多巴胺
  ③ 平台不用掏现金 → 全力做增长
```

## 三、为什么v8.0比之前所有版本都好

### 3.1 解决了每个版本的核心问题

| 版本 | 核心问题 | v8.0如何解决 |
|------|---------|------------|
| v5.0 | 太复杂，让销售员当投资人 | 三类人分开，各归其位 |
| v6.0 | 过度优化可持续性，牺牲增长 | 平台留存≈79%，同时给足激励 |
| v7.0 | 固定25%无进步感 | 阶梯佣金20-30% |
| v7.1 | 10%团队共享是永久利润税 | 团队拿期权，不占利润层 |
| 所有版本 | 让合伙人交钱交不动 | 投资单独找LP，不找销售员要钱 |

### 3.2 三个清晰的圈子

```
圈子1：销售网络（城市合伙人 × 72）
  → 纯佣金驱动，零门槛
  → 不需要理解星钻/期权/LP
  → 一句话说清楚

圈子2：核心团队（团队合伙人 × 36）
  → 期权绑定，长期主义
  → 不需要出钱，不需要做销售
  → 做自己擅长的事

圈子3：资方（投资合伙人 × 5-20）
  → 出钱拿回报，标准LP结构
  → 不需要干活，不需要拉用户
  → 投资人听得懂的语言

三个圈子互不干涉，互不竞争，各自发挥最大价值。
```
