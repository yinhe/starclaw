## 〇、虫后的战略意图

```
v3.0 的问题：
  团队合伙人和城市合伙人在同一层竞争同一块利润（每笔消费×佣金率）
  团队合伙人被迫做销售才有收入 → 不做渠道的团队成员没有收入来源
  “平台级合伙人”和“渠道代理”本质上在做同一件事

v4.0 的解法：双层利润分离
  城市合伙人 = 分渠道利润，团队合伙人 = 分平台利润
  但问题：不出钱的团队合伙人没有任何月度现金流

v6.0 的解法：三层利润分配（可持续版）
  每笔消费利润分配：
    渠道层：城市合伙人佣金 10%-20%（有归属时，3年后递减）
    合伙层：团队共享利润 10%，36席按贡献分配（不出钱也有，5年后递减至5%）
    投资层：收益池 5%，按星钻持仓分配（出钱才有，年化回报封顥50%）
    平台层：剩余 ≥65%（保底红线）

  出钱的团队合伙人：团队共享 + 收益池分红 + 星钻增值 + 股权（1%~6%）
  不出钱的团队合伙人：团队共享 + 股权（1%~6%）（也有保底收入）

  股权分层（群星模式 1+5+30，合计51%）：
    虫后 Queen      1人 × 6%  =  6%   创始人
    脑虫 Cerebrate  5人 × 3%  = 15%   联合创始人
    领主 Overlord  30人 × 1%  = 30%   团队合伙人
  城市合伙人：渠道佣金 + 收益池分红（出钱时）+ 星钻增值

  收益池投资人总计 ≤ 200 人（法律合规要求）
  孢子期满额：城市 ¥5万，团队 ¥10万
  → 早投 = 便宜拿满佣金/分红份额 + 便宜拿更多星钻 = 双重 FOMO
```

## 一、合伙人收益池

**本设计只涉及合伙人收益权，没有外部投资人。**

```
┌──────────────────────────────────────────────────┐
│              合伙人收益池（星钻）                     │
│              总量 1亿份，固定不增发                   │
│              合伙人配额：5000万份（5轮 × 1000万份）   │
│              ⚠️ 投资人总计 ≤ 200 人（法律合规上限）    │
├──────────────────────────────────────────────────┤
│ 参与者：城市合伙人 / 团队合伙人（共享同一池子）        │
│                                                    │
│ 城市合伙人购买星钻的作用：                            │
│   ① 提升佣金率（10%→20%，3年后递减）                 │
│   ② 获得收益池分红（5%，年化封顶50%）                 │
│   ③ 星钻 NAV 增值                                   │
│                                                    │
│ 团队合伙人购买星钻的作用：                            │
│   ① 获得收益池分红（5%，年化封顶50%）                 │
│   ② 星钻 NAV 增值                                   │
│   ❌ 不涉及佣金率（团队合伙人无佣金概念）              │
│   ✅ 不出钱也有团队共享利润（10%按贡献分配，5年后递减） │
│                                                    │
│ 收益池分红：月度入账 × (个人星钻 / 已发行星钻)    │
│ 团队共享：月度入账 × 贡献系数                         │
│ 每轮满员满投：360万份（72城市×2.5万+36团队×5万）       │
└──────────────────────────────────────────────────┘

星钻总量分配：
  合伙人收益池：由甲方根据平台发展需要分轮次发行
  平台预留：    剩余份额（未来战略用途，暂不流通）
  ─────────────────────
  总量上限       1亿份

注：股权期权（虫后6%+脑虫3%×5+领主1%×30=51%）与星钻是两套独立权益体系，不占星钻份额。

三层关系（v6.0 可持续版）：
  渠道层：每笔消费利润 → 城市合伙人佣金(10%-20%，3年递减)
  合伙层：每笔消费利润 → 团队共享利润(10%→5%→3%递减) → 36席按贡献
  投资层：每笔消费利润 → 收益池注入(5%) → 按星钻持仓月度分红（年化封顶50%）
  平台层：≥65%（保底红线）
  团队合伙人不参与渠道层分配，但在合伙层有保底收入
  出钱的合伙人额外享受投资层分红

合伙人席位限制：
  团队合伙人：36 席
  城市合伙人：72 席
  合计：108 人

投资人合规限制：
  星钻投资人（持有星钻的自然人/法人）累计 ≤ 200 人
  不投资的团队合伙人不计入 200 人限额（不持有星钻）
  不投资的城市合伙人不计入 200 人限额（不持有星钻）
  跨轮投资的同一人只计 1 次
```

## 二、佣金与投资机制

> **v6.0：佣金率仅适用于城市合伙人。团队合伙人无佣金概念，收入来自团队共享(10%递减) + 收益池分红(5%封顶) + 股权。**

### 2.1 基础规则

```
城市合伙人：
  不投资 → 佣金率 10%（基础，能干活但赚得少）
  投了   → 佣金率按投资额占该轮最高额的比例线性提升
  投满   → 佣金率 20%（上限，3年后递减）
  浮动区间：10%（10% → 20%）

团队合伙人：
  ❌ 无佣金率概念
  ✅ 不出钱 → 团队共享利润 10%（36席按贡献分配）5年后递减 + 股权（1%~6%按层级）
  ✅ 出钱   → 团队共享利润 + 收益池分红（5%，年化封顥50%）+ 星钻增值 + 股权（1%~6%按层级）
```

### 2.2 城市合伙人佣金率公式

**每一轮公式相同：**

```
城市合伙人佣金率 = 10% + (本轮投资额 / 本轮最高额) × 10%
满投上限 = 20%（3年后递减）
```

### 2.3 投资设计（≤20 人上限）

**城市和团队合伙人分别设限，后续轮次随价格等比上调：**

| 轮次 | 星钻价格 | 城市min | 城市max | 团队min | 团队max | 城市满额获得 | 团队满额获得 |
|------|:-------:|:------:|:------:|:------:|:------:|:----------:|:----------:|
| 孢子期 | ¥2 | ¥1万 | **¥5万** | ¥2万 | **¥10万** | 2.5万份 | 5万份 |
| 幼虫期 | ¥5 | ¥2.5万 | ¥12.5万 | ¥5万 | ¥25万 | 2.5万份 | 5万份 |
| 虫兵期 | ¥10 | ¥5万 | ¥25万 | ¥10万 | ¥50万 | 2.5万份 | 5万份 |
| 领主期 | ¥25 | ¥12.5万 | ¥62.5万 | ¥25万 | ¥125万 | 2.5万份 | 5万份 |
| 虫后期 | ¥50 | ¥25万 | ¥125万 | ¥50万 | ¥250万 | 2.5万份 | 5万份 |

> 每轮满额份数固定：城市 2.5万份，团队 5万份
> 价格递增：¥2 → ¥5 → ¥10 → ¥25 → ¥50
> **同样拿满额星钻，孢子期花 ¥5万/¥10万，虫后期花 ¥125万/¥250万 = 25倍差距**
> 每轮满员满投：72城市×2.5万 + 36团队×5万 = 360万份
> 投资人上限：累计持有星钻的自然人/法人 ≤ 200 人

**城市合伙人佣金率对照（孢子期，满额 ¥5万）：**

| 投资额 | 获得星钻 | 佣金率 |
|:------:|:-------:|:-----:|
| ¥0（不投资） | 0 份 | **10%** |
| ¥1万 | 5,000 份 | **12%** |
| ¥2.5万 | 12,500 份 | **15%** |
| ¥4万 | 20,000 份 | **18%** |
| **¥5万** | **25,000 份** | **20%** |

**团队合伙人投资对照（孢子期，满额 ¥10万，无佣金率）：**

| 投资额 | 获得星钻 | 团队共享（保底） |
|:------:|:-------:|:------------:|
| ¥0（不投资） | 0 份 | ✅ |
| ¥2万 | 10,000 份 | ✅ |
| ¥5万 | 25,000 份 | ✅ |
| **¥10万** | **50,000 份** | ✅ |

> **v6.0 变化：** 城市满额佣金率从30%降至20%，收益池从10%降至5%。
> 团队合伙人的差异化：团队共享利润(10%递减) + 股权（领主1%/脑虫3%/虫后6%）。
> 所有比例设日落递减机制，确保平台长期可持续。

### 2.4 关键洞察：双重 FOMO

```
城市合伙人 — 佣金率 FOMO：
  要拿到 20% 满额佣金：
    孢子期投满 → 花 ¥5万
    幼虫期投满 → 花 ¥12.5万    （贵 2.5 倍）
    虫兵期投满 → 花 ¥25万      （贵 5 倍）
    虫后期投满 → 花 ¥125万     （贵 25 倍）

所有合伙人 — 星钻份额 FOMO：
  同样花 ¥5万：
    孢子期 → 25,000份星钻（占比高 → 分红多）
    虫后期 → 1,000份星钻  （占比低 → 分红少，差 25 倍）

结论：早投 = 便宜拿满佣金率 + 便宜拿更多星钻 = 双重 FOMO
```

### 2.5 计算示例

```
例1：城市合伙人在孢子期投满 ¥5万（最高 ¥5万）
  佣金率 = 10% + (5/5) × 10% = 10% + 10% = 20%
  获得星钻 = ¥5万 / ¥2 = 25,000份
  → 渠道佣金 + 收益池分红双收

例2：城市合伙人在幼虫期投 ¥2万（最低 ¥2.5万）
  → 低于最低投资额，不能投。必须至少投 ¥2.5万。
  如果投 ¥6万（半额）：佣金率 = 10% + (6/12.5) × 10% = 14.8%
  获得星钻 = ¥6万 / ¥5 = 12,000份

例3：团队合伙人在孢子期投满 ¥10万
  获得星钻 = ¥10万 / ¥2 = 50,000份
  假设收益池已发行100万份 → 占比 5%
  → 无佣金率（团队合伙人不参与渠道分配）
  → 团队共享 = 每笔消费利润 × 贡献系数（不论是否投资）
  → 收益池月分红 = 月收益池入账 × 5%（额外收入，年化封顶50%）

例4：团队合伙人在虫兵期投满 ¥50万
  获得星钻 = ¥50万 / ¥10 = 50,000份
  → 同样 50,000份星钻，孢子期花 ¥10万，虫兵期花 ¥50万（贵 5 倍）
```

### 2.6 跨轮投资规则

```
城市合伙人：多轮投资时，佣金率取各轮最高值。
同一轮可以分多次投资，系统按轮次聚合总额计算佣金率。

例：城市合伙人
  孢子期投满 ¥5万 → 佣金率 20%，获 25,000份星钻
  幼虫期再投 ¥6万（半额） → 本轮佣金率 = 10% + (6/12.5)×10% = 14.8%
  
  生效佣金率 = max(20%, 14.8%) = 20%（孢子期更高）
  累计星钻 = 25,000 + 12,000 = 37,000份（收益池分红也增加）

如果幼虫期投满 ¥12.5万：
  本轮佣金率 = 20%
  生效佣金率 = max(20%, 20%) = 20%
  累计星钻 = 25,000 + 25,000 = 50,000份

团队合伙人：无佣金率计算，多轮投资纯粹增加星钻持仓。
  孢子期投满 ¥10万 → 获 50,000份星钻
  幼虫期再投满 ¥25万 → 获 50,000份星钻
  累计星钻 = 100,000份 → 收益池分红份额翻倍
  团队共享利润不受投资额影响

⚠️ 200 人上限管理：
  跨轮投资的同一人只计 1 次
  系统维护唯一投资人名单（DiamondHolderRegistry）
  新投资人加入前校验：当前唯一持有人数 < 200
```

## 三、利润分配架构 — 三层模型（v6.0 可持续版）

### 3.1 三层分配

每笔 AI 消费利润，按四个方向实时分账。团队共享和收益池月度结算。

```
  ╔══════════════════════════════════════════════════╗
  ║  渠道层（每笔消费实时结算）                          ║
  ╠══════════════════════════════════════════════════╣
  ║  城市合伙人渠道佣金：10%-20%（有归属时，3年后递减）    ║
  ╚══════════════════════════════════════════════════╝

  ╔══════════════════════════════════════════════════╗
  ║  合伙层（每笔消费注入，月度结算）                     ║
  ╠══════════════════════════════════════════════════╣
  ║  团队共享利润：10%（前5年）→ 5%（5-10年）→ 3%（10年+）║
  ║  36席按贡献分配，不出钱也有 ✓                        ║
  ╚══════════════════════════════════════════════════╝

  ╔══════════════════════════════════════════════════╗
  ║  投资层（每笔消费注入，月度结算）                     ║
  ╠══════════════════════════════════════════════════╣
  ║  收益池：5% → 按星钻持仓比例分红（年化回报封顶50%）   ║
  ║  城市+团队投资者一视同仁                             ║
  ╚══════════════════════════════════════════════════╝

  ╔══════════════════════════════════════════════════╗
  ║  平台层（≥65%，保底红线）                            ║
  ╠══════════════════════════════════════════════════╣
  ║  研发 / 运营 / 获客 / 储备                          ║
  ╚══════════════════════════════════════════════════╝
```

### 3.2 场景矩阵（每笔消费利润分配，前5年）

| 场景 | 城市佣金 | 团队共享 | 收益池 | 平台 | 合计 |
|------|:------:|:------:|:-----:|:---:|:---:|
| 城市合伙人（满投 20%） | 20% | 10% | 5% | **65%** | 100% |
| 城市合伙人（半投 15%） | 15% | 10% | 5% | **70%** | 100% |
| 城市合伙人（不投 10%） | 10% | 10% | 5% | **75%** | 100% |
| 无城市合伙人归属 | — | 10% | 5% | **85%** | 100% |

> 团队共享和收益池 **每笔消费都注入**，不论客户是否归属城市合伙人。
> 平台在任何场景下留存 **≥65%**，确保运营可持续。

### 3.3 月度结算分配

| 分配方 | 来源 | 分配方式 | 分红公式 |
|-------|------|---------|---------|
| 团队合伙人（36席） | 团队共享池 | 按贡献分配 | 月团队共享池 × 贡献系数 |
| 城市合伙人（有星钻） | 收益池 | 按星钻持仓 | 月收益池 × (个人星钻 / 总发行星钻) |
| 团队合伙人（有星钻） | 收益池 | 按星钻持仓 | 月收益池 × (个人星钻 / 总发行星钻) |
| 团队合伙人 | 股权 | 年度 | 年度可分配利润 × 股权比例（1%~6%） |

> 城市合伙人和团队合伙人在收益池分红上**一视同仁**，按星钻持仓比例分配，不区分身份。
> 团队共享利润**只有团队合伙人**享有，城市合伙人不参与。

### 3.4 可持续性机制

**① 城市佣金递减（3年日落）：**
```
前3年：佣金率 = 10% + (投资额/最高额) × 10%    → max 20%
第4-5年：佣金率 × 70%                           → max 14%
第6年起：佣金率 × 50%                           → max 10%
新归属客户：始终按当前佣金率（激励持续拓新客）
```

**② 团队共享利润递减（5年日落）：**
```
前5年：  10%（创业期，需要强激励绑定核心团队）
第6-10年：5%（成长期，团队稳定后降低比例）
第11年起：3%（成熟期，平台自运转）

释放出的比例归入平台层，用于员工激励和研发投入。
```

**③ 收益池回报封顶（50%年化上限）：**
```
每月分红时计算：
  如果 年化累计分红 / 投资本金 > 50%
  → 超出部分不分配，留存在收益池中（推高NAV）

效果：
  投资 ¥10万 → 年分红上限 ¥5万（月 ¥4,167）
  防止平台成熟期出现300%+年化回报的失控局面
  超出部分沉淀为NAV增值，退出时一次性实现
```

**④ 平台保底红线（≥65%）：**
```
任何场景下，平台留存 ≥ 消费利润的65%
如果渠道层+合伙层+投资层合计超过35%，按比例缩减（平台留存优先）
实际上：城市满投(20%) + 团队(10%) + 收益池(5%) = 35% ✓ 恰好卡在红线
```

**铁律（v6.0）：**
- 城市合伙人：渠道佣金 max 20%（3年递减）+ 收益池分红（出钱才有，回报封顶50%/年）
- 团队合伙人：团队共享（保底，5年后递减）+ 收益池分红（出钱才有，回报封顶50%/年）+ 股权
- 团队合伙人**不从单笔消费中抽佣**
- 平台 **至少 65%**（保底红线），**最高 85%**（无城市归属时）
- 所有比例设日落机制，防止长期寄生

## 四、城市合伙人年费 vs 星钻投资

### 4.1 当前方案：两套并存

| 机制 | 年费 | 合伙人收益权（星钻） |
|------|------|-----------------|
| 性质 | 合作服务费（沉没成本） | 投资（有分红+增值+佣金提升） |
| 决定什么 | 合伙人资格准入 | 城市：**佣金率**（10%→20%）+ 分红；团队：分红份额 |
| 是否退还 | 不退（次年签≥3客户可返还） | 按协议到期NAV结算退出 |

**虫后的判断：** 年费和收益权投资**解决不同问题**：

- **年费** → 准入门槛，筛选合作诚意
- **收益权投资** → 决定佣金率高低 + 绑定长期利益 + 参与收益池分红

### 4.2 长期演进（待讨论）

```
Phase 1（现在）：年费 + 收益权投资并存
  年费 → 合伙人准入资格
  收益权投资 → 决定佣金率（10%~20%）+ 收益池分红（5%）

Phase 2（规模化后）：年费可抵扣投资购买
  认证级年费 ¥9,800 → 可抵扣 ¥9,800 的星钻购买
  区域独家年费 ¥29,800 → 可抵扣 ¥29,800 的星钻购买
  效果：交年费 = 自动获得对应金额的星钻 → 佣金率自动提升

Phase 3（成熟期）：取消年费，纯收益权投资门槛
  星钻投资 ≥ 当前轮最低额 → 自动获得合伙人资格
  年费消失，全部转为收益权投资
```

> Phase 2 和 Phase 3 暂不实施，先跑通 Phase 1 验证模式。

## 五、合伙人收益模型

### 5.1 城市合伙人收益结构

```
┌─ 收益① 佣金收入（即时，每笔消费）
│    归属客户消费利润 × 佣金率
│    佣金率 = 10%（不投资）~ 20%（投满当前轮，3年后递减）
│
├─ 收益② 收益池分红（月度，按星钻持仓）
│    月利润 × 5% × (个人星钻 / 收益池总星钻)（年化封顥50%）
│    投了星钻才有星钻，才有分红
│
└─ 收益③ 星钻增值（长期，NAV驱动）
     买入价 → NAV上涨 → 持仓市值增长
     到期可按NAV退出
```

### 5.2 团队合伙人收益结构（v6.0）

```
┌─ 收益① 团队共享利润（月度，保底现金流）
│    月总利润 × 10% × (1/36)
│    不出钱也有！36席均分
│
├─ 收益② 收益池分红（月度，出钱才有）
│    月利润 × 5% × (个人星钻 / 收益池总星钻)（年化封顥50%）
│    投了星钻才有星钻，才有分红
│    ❌ 无渠道佣金（团队合伙人不参与渠道层分配）
│
├─ 收益③ 股权分红（年度，按层级）
│    公司年度可分配利润 × 股权比例（领主1%/脑虫3%/虫后6%）
│    公司盈利后开始
│
├─ 收益④ 星钻增值（长期，NAV驱动）
│    投资购买的星钻随NAV上涨
│
└─ 收益⑤ 股权增值（长期，独立于收益池）
     股权期权（1%~6%）→ 仅享有增值权
     股权期权与星钻独立，不参与收益池 5% 分红
```

> **v6.0 可持续版：** 团队合伙人有保底收入（团队共享10%按贡献分配，5年后递减），不出钱也有。
> 出钱的额外获得收益池分红（5%，年化封顥50%），形成“保底+激励”双层结构。
> 团队合伙人关心的是整个平台的成功，而非某几个客户的消费。

> **股权期权不参与收益池分红。** 股权只享有增值权（NAV上涨受益），
> 收益池 5% 分红只分给通过投资购买的星钻持有人。

### 5.3 收益测算

**案例 A：城市合伙人，孢子期投满 ¥5万（佣金率 20%）**

```

投资 ¥5万（本轮最高额）→ 佣金率 = 10% + (5/5)×10% = 20%
买到星钻 = ¥5万 / ¥2 = 25,000份
假设收益池已发行 100万份 → 占比 2.5%

假设：
  归属客户 10 家，月均消费利润 ¥2,000/家 = ¥20,000 利润
  平台月总利润 ¥500,000
  收益池月入 ¥25,000（月总利润 × 5%）

月收入：
  佣金     = ¥20,000 × 20%           = ¥4,000
  收益池分红 = ¥25,000 × 2.5%          = ¥625
  ──────────────────────────────────────
  合计                                 = ¥4,625/月

年收入约 ¥55,500
额外：星钻增值（若NAV涨到¥10） = 25,000 × ¥10 = ¥25万
⚠️ 回报封顶：年分红上限 = ¥5万投资 × 50% = ¥2.5万/年（月 ¥2,083）
```

```
InternalProfitSplit(clawID, cost, margin):

  // 1. 加载全局配置
  cfg = LoadProfitConfig()
  // cfg.BaseCommRate      = 0.10   // 基础佣金率（不投资时）
  // cfg.CityMaxRate       = 0.20   // 城市合伙人最高佣金率（v6.0：30%→0%）
  // cfg.TeamSharedRate    = 0.10   // 团队共享利润恒定比例（v5.0 新增）
  // cfg.OptionPoolRate    = 0.05   // 收益池恒定比例（v6.0：10%→5%）
  // cfg.TeamSeats         = 36     // 团队合伙人席位数

  // 2. 找到归属的城市合伙人
  user = NodeBinding[clawID].QueenUserID
  cityPartner = FindCityPartner(user)

  // 3. 城市合伙人渠道佣金（按投资额决定佣金率）
  if cityPartner exists:
    rate = CalcCityCommRate(cityPartner)
    commAmt = margin × rate
    → INSERT Commission(cityPartner, commAmt, "channel", rate=rate)

  // 4. 团队共享利润注入（10%）—— v5.0 新增，永远执行
  teamSharedAmt = margin × cfg.TeamSharedRate  // margin × 0.10
  → UPDATE TeamSharedPool SET balance += teamSharedAmt
  → INSERT TeamSharedDeposit(teamSharedAmt, margin, clawID)

  // 5. 收益池注入（5%）—— 永远执行
  poolAmt = margin × cfg.OptionPoolRate  // margin × 0.05
  → UPDATE OptionPool SET pool_balance += poolAmt
  → INSERT PoolDeposit(poolAmt, margin, "token_usage", clawID)

  // 6. 平台留存 = margin - commAmt - teamSharedAmt - poolAmt
  //    最少 50%（城市满投时），最多 80%（无城市合伙人时）


// ── 月度团队共享利润分配（v5.0 新增） ──
MonthlyTeamSharedDistribute():
  distributable = TeamSharedPool.balance
  activeTeamPartners = FindActiveTeamPartners()  // 最多 36 席
  perSeat = distributable / len(activeTeamPartners)
  
  for each partner in activeTeamPartners:
    → INSERT Dividend(partner, perSeat, "team_shared")
  
  → UPDATE TeamSharedPool SET balance -= distributed_total


// ── 月度收益池分红（团队+城市合伙人共享） ──
MonthlyOptionPoolDistribute():
  distributable = OptionPool.pool_balance
  totalShares = SUM(all partner option_shares)  // 城市+团队
  
  for each partner with option_shares > 0:
    share = partner.option_shares / totalShares
    dividend = distributable × share
    → INSERT Dividend(partner, dividend, "option_pool")
  
  → UPDATE OptionPool SET pool_balance -= distributed_total


// ── 城市合伙人佣金率计算函数（含过渡期） ──
CalcCityCommRate(partner):
  // 过渡期：返回旧佣金率
  if partner.transition_end != nil AND now < partner.transition_end:
    return partner.legacy_comm_rate

  // 正常计算：按投资额决定（仅城市合伙人）
  baseRate = 0.10
  rateRange = 0.20   // 10% → 30%
  bestRate = baseRate

  // 按轮次聚合投资额（同一轮可多次投资，取 SUM）
  roundTotals = GROUP BY round.name, SUM(round.amount)
    FROM partner.option_investments

  for each (roundName, totalAmount) in roundTotals:
    roundMax = getRoundMax(roundName)  // v5.0：城市和团队统一限额
    roundRate = baseRate + (totalAmount / roundMax) × rateRange
    bestRate = max(bestRate, roundRate)

  return clamp(bestRate, baseRate, 0.20)


// ── 投资人 200 人上限校验（v5.0 新增） ──
ValidateInvestorCap(partnerID):
  existingHolder = DiamondHolderRegistry.Find(partnerID)
  if existingHolder != nil:
    return OK  // 已有持有人，不占新名额

  totalHolders = DiamondHolderRegistry.Count()
  if totalHolders >= 200:
    return ERROR("投资人已达200人上限，暂停接受新投资")
  
  return OK
```

### 9.1 佣金阶梯制度（CommissionTier）— 被替代

**旧制度：** 合伙人按累计业绩分级（铜10%/银15%/金20%/钻石25%），被动递增。

**新制度：** 佣金率由**收益权投资额**决定（10%→20%，3年后递减），主动投入。

| 维度 | 旧（CommissionTier） | 新（收益权佣金绑定） |
|------|---------------------|-------------------|
| 决定因素 | 累计消费利润（被动） | 收益权投资额（主动） |
| 调整方式 | 到达门槛自动升级 | 投多少立即生效 |
| 城市合伙人范围 | 10%~25% | 10%~30% |
| 团队合伙人范围 | 10%~25% | ❌ 无佣金（团队共享10%均分） |
| 退出成本 | ¥0（走就走） | 有（星钻锁在池子里） |

> `DefaultCommissionTiers` 在新方案上线后**废弃**，改用 `CalcCityCommRate`。

### 9.2 星钻系统

复用已有的 InvestorPool（改名 OptionPool）、FundingRound、PoolDeposit 底层结构。变化：

- `InvestorPool` → `OptionPool`（改名，只服务合伙人）

- 合伙人购买走新的 `PartnerOptionInvestment` 表
- 分红逻辑复用，只分给星钻持有人（股权期权不参与）

## 十、飞轮效应 — 为什么这个设计能赢

```
  ┌────────────────────────────────────────────────────────────┐
  │                    三层飞轮效应（v6.0 可持续版）                        │
  │                                                            │
  │  城市合伙人投资星钻 ←── 佣金率提升+分红 ←─────────────────┐  │
  │       │                                                │  │
  │       ├→ 佣金率 20% → 每笔消费赚更多 → 更积极拓客       │  │
  │       └→ 星钻份额 → 收益池分红（额外奖励）              │  │
  │              │                                         │  │
  │              ▼                                         │  │
  │       更多用户 → 更多 AI 消费 → 更多利润                 │  │
  │              │                                         │  │
  │              ├→ 利润 × 佣金率 → 城市合伙人赚更多 ──────┘  │
  │              ├→ 利润 × 10% → 团队共享池 ──────────────┐   │
  │              ├→ 利润 × 5% → 收益池 ────────────────┌│   │
  │              └→ 利润 × ≥65% → 平台能力增强 ──────┐   ││   │
  │                                                 │   ││   │
  │  团队合伙人（不出钱）←── 团队共享保底 ←──────────┘←──┘│   │
  │       │                                              │   │
  │       ├→ 各角色发挥专长                               │   │
  │       │   战略型引资源 / 技术型做产品                   │   │
  │       │   市场型拓大客 / 渠道型建网络                   │   │
  │       │                                              │   │
  │  团队合伙人（出钱）←── 共享+分红双收 ←───────────────┘   │
  │       └→ 星钻份额 → 收益池分红（额外现金流）              │
  │              + 团队共享（保底）+ 股权增值（1%~6%按层级） │
  │                                                         │
  └─────────────────────────────────────────────────────────┘
                                                              
  关键：不出钱的团队合伙人有保底 → 愿意加入                     
        出钱的团队合伙人有额外激励 → 愿意投资                   
        城市合伙人驱动渠道增长，团队合伙人驱动平台能力           
```

**四重正反馈：**
1. **城市佣金率正反馈：** 投资 → 佣金率高 → 每笔赚更多 → 更积极拓客 → 更多用户
2. **团队共享正反馈：** 更多利润 → 团队共享池更大 → 每席分更多 → 团队更有动力
3. **收益池分红正反馈：** 更多利润 → 收益池入账更多 → 分红增长 → 吸引更多投资
4. **团队能力正反馈：** 团队合伙人贡献 → 平台更强 → 用户更多 → 利润更高 → 分红更多

### 与传统模式对比

| 维度 | 传统合伙人 | v5.0 三层模型 |
|------|----------|--------------|
| 城市合伙人佣金 | 固定比例 | **投多少决定多少**（10%→20%，3年递减） |
| 团队合伙人收入 | 固定佣金+管理费 | **团队共享(保底)+收益池分红+股权** |
| 不出钱的团队 | 无收入 | **有保底**（团队共享10%均分36席） |
| 团队合伙人角色 | 必须做渠道管理 | **多元化**（战略/技术/市场/运营/渠道） |
| 关心范围 | 只关心自己客户 | 城市关心渠道，团队关心**全平台** |
| 退出成本 | ¥0（走就走） | 投资锁在池子里 |
| 资金贡献 | ¥0 | 真金白银投入平台（≤200人） |
| FOMO | 无 | **双重FOMO**（早投便宜拿佣金率+便宜拿星钻） |

## 十一、风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 城市合伙人不愿投资 | 佣金率停在10%，参与度低 | ① 10%也能干活，不强制 ② 用案例展示投资后收益差距（¥50万→15%） |
| 团队合伙人早期收入低 | 平台利润小时团队共享少 | v6.0 已有保底（团队共享10%按贡献分配，5年后递减），+股权@IPO（领主¥5300万/脑虫¥1.6亿） |
| 新合伙人加入时已是后期轮次 | 拿满佣金率/分红份额成本高 | 早投优势是设计意图，后期可平台补贴星钻折扣 |
| 合伙人误解为"承诺收益" | 法律风险 | 协议明确"按实际利润分配"，前端不显示预期收益率 |
| 监管风险（类金融） | 合规问题 | **严格控制投资人≤200人** + 不公开募集 + 收益权协议框架 |
| 200人上限不够用 | 优质合伙人无法投资 | ¥50万起投门槛自然筛选；不投资也能当合伙人（只是没分红） |
| 佣金率计算复杂 | 系统出bug | `CalcCityCommRate` 单元测试覆盖所有边界 |
| 过渡期成本 | 旧佣金率高于10%的城市合伙人短期不受激励 | 过渡期内积极沟通 + 展示早期低价优势促成投资 |
| 团队合伙人角色模糊 | 贡献难以量化 | 签约时选定角色标签 + 对应里程碑明确量化 |
| 团队共享"搭便车" | 不贡献也分钱 | 角色里程碑+股权归属机制约束；未达标可取消席位 |

## 十二、现有合伙人过渡方案

**已确认：有过渡期，先预留旧佣金率，之后需补交（投资星钻）。**

```
过渡规则（先用后付）：
  上线后，现有合伙人保持当前佣金率（过渡期，如3个月）
  过渡期内：
    ① 佣金率 = 旧佣金率（预留，继续正常干活）
    ② 合伙人可以随时投资星钻
    ③ 如果投资后的收益权佣金率 ≥ 旧佣金率 → 过渡完成，切换到新制度
    ④ 系统记录过渡期内按旧佣金率多发的差额（= 旧佣金率 - 10%基础）

  过渡期结束时：
    A) 已投资够 → 佣金率 = CalcPartnerCommRate()（≥ 旧佣金率）
       过渡期差额一笔勾销
    B) 未投资够 → 佣金率 = CalcPartnerCommRate()（可能 < 旧佣金率）
       过渡期差额需要补交（从后续佣金中扣回，或一次性投资补齐）

补交方式（二选一）：
  方式1：从后续佣金中逐月扣回差额，直到扣完
  方式2：一次性追加投资星钻，达到对应佣金率后免除差额

例：城市合伙人旧佣金率 25%，过渡期 3 个月
  过渡期每月归属利润 ¥20,000
  差额 = (25% - 10%) × ¥20,000 × 3个月 = ¥9,000
  如果过渡期内投满孢子期 ¥5万 → 佣金率 30% ≥ 25% → 差额免除
  如果过渡期结束仍未投资 → ¥9,000 从后续佣金逐月扣回

实现方式：
  合伙人表新增字段：
    legacy_comm_rate  float64   // 旧佣金率（过渡期用）
    transition_end    time.Time // 过渡期截止日期
    transition_debt   int64     // 过渡期累计差额（分）
  CalcPartnerCommRate 判断：
    if now < transition_end:
      return legacy_comm_rate  // 预留旧佣金率
    else:
      return 新计算佣金率      // 按实际投资额算
  佣金发放时：
    if transition_debt > 0 AND 过渡期已结束:
      实际发放 = 本期佣金 - min(本期佣金×30%, transition_debt)
      transition_debt -= 扣回金额
```

## 十四、团队合伙人角色标签制

团队合伙人不再绑定"渠道管理"单一角色。签约时选择角色标签，对应不同职责和里程碑。

### 14.1 角色标签

| 角色标签 | 核心贡献 | 适合人群 |
|---------|---------|---------|
| **战略型** | 资源引入、融资对接、商务合作 | 有行业资源和人脉的合伙人 |
| **市场型** | 品牌推广、大客户直签、行业拓展 | 有销售和市场经验的合伙人 |
| **技术型** | 产品研发、技术方案、客户集成 | 有技术背景的合伙人 |
| **运营型** | 团队管理、流程优化、客户成功 | 有运营管理经验的合伙人 |
| **渠道型** | 发展城市合伙人网络、区域管理 | 有渠道资源的合伙人 |

### 14.2 各角色里程碑（股权归属 4×25%）

**战略型：**
1. 引入 1 个战略合作伙伴（甲方认可）
2. 促成 1 笔融资对接或重大合作落地
3. 季度内平台因合伙人资源新增收入 ≥ ¥10万
4. 连续 2 个季度达成里程碑 3

**市场型：**
1. 签约 3 个直签企业客户
2. 直签客户月消费 ≥ ¥5万
3. 季度佣金/贡献收入 ≥ ¥3万
4. 直签客户累计 ≥ 10 家

**技术型：**
1. 完成 3 个客户技术集成/方案交付
2. 客户月活跃率 ≥ 80%
3. 季度技术服务贡献 ≥ ¥3万
4. 集成客户累计 ≥ 10 家

**运营型：**
1. 建立标准化运营流程（甲方验收通过）
2. 客户满意度/NPS ≥ 目标值
3. 季度运营效率提升可量化（成本降低/效率提高）
4. 连续 2 个季度达成里程碑 3

**渠道型：**
1. 招募 3 名活跃城市合伙人（各有 ≥1 客户）
2. 下辖城市合伙人月消费利润 ≥ ¥5万
3. 季度渠道贡献收入 ≥ ¥3万
4. 下辖月活客户 ≥ 100

> **角色可变更：** 经甲方批准，团队合伙人可申请变更角色标签，变更后里程碑重新计算。
> 已归属的股权不受角色变更影响。
