# Extractor v2 — AI 增强量化交易系统架构

## 一、重新思考：AI 在交易中到底能做什么

### 1.1 AI 不能做什么（必须先说清楚）

- **不能稳定预测明天涨跌** — 如果能，所有对冲基金早就用了
- **不能保证每只股票都盈利** — 任何系统都做不到，关键是胜率和赔率
- **不能替代风控纪律** — AI 可能很自信地给出错误判断

### 1.2 AI 真正能做的（这些是实实在在的价值）

| 能力 | 具体应用 | 传统量化能做到吗 |
|------|---------|----------------|
| **语义理解** | 读懂财报、公告、新闻，判断利好/利空 | 不能 |
| **因果推理** | "美联储加息 → 人民币承压 → 出口企业受影响" | 不能 |
| **多源信息融合** | 同时考虑技术面+消息面+资金面+情绪面 | 勉强（需要大量规则） |
| **自适应策略** | 根据市场阶段动态调整参数 | 需要人工调参 |
| **自然语言交互** | 用中文解释为什么买、为什么卖 | 不能 |
| **异常检测** | "这只票涨幅异常，可能有未公开消息" | 部分能 |

### 1.3 核心设计理念

```
不是让 AI 替代量化，而是让 AI 成为量化的"大脑"，量化成为 AI 的"手脚"。

量化负责：快速计算、精确执行、纪律止损
AI 负责：理解世界、判断方向、识别风险、解释决策
```

## 二、整体架构 — Claw+Worker 融合节点

### 2.1 核心理念

**每个节点既是执行者（Worker），也有自己的大脑（Claw）。**

Master 负责全局协调，但不是唯一决策者。每个节点可以在 Master 离线时自主运行。

这就像军队：**总部制定战略，前线指挥官自主决定战术。**

### 2.3 与传统 Master-Worker 的区别

| 对比项 | 传统 Master-Worker | Claw+Worker 融合 |
|--------|-------------------|------------------|
| 节点智能 | Worker 无脑执行 | 每个节点有本地 AI |
| Master 宕机 | 全部瘫痪 | 节点自治，继续运行 |
| 决策延迟 | 高（上报→分析→返回） | 低（本地直接判断） |
| 扩展性 | 加节点 = 加手 | 加节点 = 加一个有脑子的交易员 |
| 算力消耗 | 集中在 Master | 分布式，按需激活 |

## 三、Master — 决策中心

### 3.1 AI 大脑模块

AI 大脑不是一个单一的 LLM 调用，而是一套**分层决策系统**：

```
Layer 1: 宏观层（每天 1-2 次）
├── 输入: 全球财经新闻、央行政策、外盘走势、汇率变动
├── 输出: 今日市场方向判断（进攻/防守/观望）
├── 影响: 决定总仓位水位（满仓/半仓/空仓）
└── 模型: 大模型 + 联网搜索（实时新闻）

Layer 2: 行业层（每天 2-3 次）
├── 输入: 行业资金流、板块涨跌、政策解读、产业链变动
├── 输出: 今日重点行业（做多/回避）
├── 影响: 选股范围过滤
└── 模型: 大模型 + 行业数据 API

Layer 3: 个股层（盘中实时）
├── 输入: 量化打分 + 个股公告 + 龙虎榜 + 资金流向
├── 输出: 具体买入/卖出/持有决策
├── 影响: 最终交易指令
└── 模型: 大模型 + 量化引擎联合决策

Layer 4: 风控层（全程运行）
├── 输入: 持仓状态、盈亏情况、市场波动率
├── 输出: 止损/止盈/减仓指令
├── 影响: 覆盖所有其他层的决策
└── 模型: 规则引擎 + AI 异常检测
```

### 3.2 AI 大脑的具体工作流

#### 盘前（08:00 - 09:15）

```
1. [宏观扫描]
   - 抓取隔夜美股、欧股、A50期指、汇率、商品期货
   - 抓取当日财经要闻（财联社/东方财富/新浪财经）
   - AI 分析: "今天大盘大概率怎么走？哪些板块会受益/受损？"
   - 输出: 市场方向 + 仓位建议 + 重点板块

2. [选股池生成]
   - 量化引擎扫描全 A 股技术面（现有策略）
   - AI 对候选股逐一检查:
     * 最近有没有利空公告？
     * 所在行业今天是利好还是利空？
     * 主力资金近 3 日净流入还是净流出？
   - 输出: 精选买入池（附带 AI 分析理由）

3. [持仓复盘]
   - 检查昨日持仓的每只票:
     * 基本面有没有变化？
     * 技术面还健康吗？
     * 该继续持有、加仓、还是准备卖出？
   - 输出: 持仓操作计划
```

#### 盘中（09:30 - 15:00）

```
4. [买点识别]
   - 对买入池中的票实时监控:
     * 开盘价相对于昨收位置
     * 前 15 分钟量能
     * 是否出现理想的回踩/突破形态
   - AI 综合判断: "现在买合适吗？还是再等等？"
   - 输出: 买入指令（价格、数量、账号分配）

5. [卖点识别]
   - 对持仓票实时监控:
     * 到达目标价位？
     * 出现放量滞涨/高位十字星？
     * 板块开始走弱？
     * 触发止损线？
   - AI 综合判断: "现在该卖吗？卖多少？"
   - 输出: 卖出指令

6. [盘中事件响应]
   - 实时监听突发新闻:
     * 央行降息 → 利好银行/地产 → 加仓相关持仓
     * 某公司暴雷 → 紧急卖出
     * 板块异动 → 快速分析原因 → 决定是否跟进
   - 输出: 紧急交易指令
```

#### 盘后（15:00 - 17:00）

```
7. [日终复盘]
   - 今日操作回顾: 买了什么、卖了什么、盈亏多少
   - AI 自我评估: "今天哪些决策对了？哪些错了？为什么？"
   - 策略参数微调建议
   - 明日观察池生成
   - 输出: 日报（推送到 Web 大屏 + 微信通知）
```

### 3.3 量化引擎增强

在 AI 大脑之外，量化引擎本身也要升级：

```
现有能力:
  ✅ 技术面打分（趋势+量价+波动率）
  ✅ 全 A 股扫描
  ✅ 自动下单

需要新增:
  🆕 买点模型 — 不只是"选什么"，还要知道"什么价格买"
     ├── 支撑位识别（均线/前低/筹码密集区）
     ├── 突破确认（放量过前高+回踩不破）
     └── 集合竞价分析（开盘前判断今天走势强弱）

  🆕 卖点模型 — 目前只有买没有卖
     ├── 目标价计算（基于 ATR / 前高 / 黄金分割）
     ├── 动态止盈（浮盈达到 X% 后启动追踪止盈）
     ├── 止损纪律（固定止损 + AI 判断是否该提前走）
     └── 时间止损（持仓 N 天不涨则离场）

  🆕 仓位管理
     ├── 凯利公式计算最优仓位
     ├── 分批建仓（不要一次买满）
     ├── 账户间资金分配
     └── 总仓位与市场环境联动
```

## 四、Claw+Worker 融合节点

### 4.1 节点内部结构

```
Claw+Worker 融合节点（一台 Windows 电脑/服务器）
│
├── Claw AI（本地大脑，可休眠）
│   ├── 本地 LLM 或远程 API（按需唤醒）
│   ├── 个股分析 / 买卖点判断
│   ├── 本地风控异常检测
│   └── Master 离线时接管决策
│
├── 量化引擎（轻量本地副本）
│   ├── 对 Master 候选池中的票做技术面验证
│   ├── 实时监控持仓的止盈/止损
│   └── 自治模式下可独立扫描选股
│
├── Python Bridge (:8098)
│   ├── 接收 Master 指令 或 本地 Claw 指令
│   ├── 执行买卖操作
│   ├── 上报持仓/成交/资金状态
│   └── 本地风控（断网保护、紧急止损）
│
└── QMT 客户端（登录真实/模拟账号）
```

### 4.2 三种运行模式

```
Mode 1: 从属模式（Follower）— Master 在线，默认
├── Claw AI:  💤 休眠（不调用 LLM，零算力消耗）
├── 决策来源: 100% 来自 Master
├── 节点职责: 只执行 Master 指令 + 上报状态
├── 适用场景: 日常正常运行
└── 算力消耗: 极低

Mode 2: 协作模式（Collaborator）— Master 在线 + 启用 Claw
├── Claw AI:  ⚡ 活跃（做二次确认/买卖点优化）
├── 决策来源: Master 选股 → 本地 Claw 复核
├── 节点职责: 执行 + 本地风控 + AI 复核 + 买卖点微调
├── 适用场景: 需要更高决策质量时手动开启
└── 算力消耗: 中等

Mode 3: 自治模式（Autonomous）— Master 离线，自动切换
├── Claw AI:  🔥 完全接管决策
├── 决策来源: 100% 本地 Claw + 量化引擎
├── 节点职责: 独立选股 + 独立买卖 + 独立风控
├── 适用场景: Master 宕机/断网时自动进入
└── 算力消耗: 高（但生存优先于省电）
```

### 4.3 模式自动切换逻辑

```
每 10 秒心跳检测:

  Master 响应? ──→ 是 → 保持当前模式（从属或协作）
                  否 → 连续 3 次失败（30 秒）?
                        ├── 否 → 继续重试
                        └── 是 → 进入自治模式
                                 ├── 1. 唤醒本地 Claw AI
                                 ├── 2. 加载保守策略参数
                                 ├── 3. 日志标记: "AUTONOMOUS MODE ACTIVATED"
                                 ├── 4. 通知大屏/微信告警
                                 └── 5. 每 30 秒尝试重连 Master

  Master 恢复:
  → 同步自治期间的操作记录给 Master
  → Master 确认后，Claw 降回休眠
  → 恢复从属/协作模式
```

### 4.4 自治模式的安全约束

**自治模式不是"放飞自我"，而是"保守自保"：**

| 参数 | Master 在线（正常） | 自治模式（保守） |
|------|-------------------|----------------|
| 新开仓 | 允许 | 默认禁止（除非 Claw 置信度 > 90%） |
| 仓位上限 | 80% | 降到 50% |
| 止损线 | -5% | 收紧到 -3% |
| 操作频率 | 实时 | 每 5 分钟一次 |
| 核心目标 | 盈利最大化 | 保护现有持仓，等 Master 回来 |

### 4.5 算力弹性调度

不只是"开/关"，而是按场景动态调配 AI 的思考深度：

```
空闲时（盘后/非交易日）:
  → Claw 做深度复盘、策略优化
  → 用大模型（Qwen-72B / DeepSeek-V3）
  → 不赶时间，质量优先

盘中轻负载（持仓不多、无异动）:
  → Claw 只做简单监控
  → 用小模型（Qwen-7B）或纯规则引擎
  → 几乎不消耗 GPU

盘中重负载（闪崩/暴涨/突发事件）:
  → Claw 全力运转
  → 用最强可用模型，快速分析
  → GPU 拉满，速度优先

Master 宕机:
  → 不管当前负载，立刻启动完整 Claw
  → 自保优先，算力其次
```

## 七、你没想到但很关键的点

### 7.1 AI 的"知道自己不知道"

最危险的不是 AI 判断错误，而是 **AI 很自信地判断错误**。

系统必须有：
- **置信度输出** — 每个决策附带置信度，低于阈值不执行
- **人工确认模式** — 大额交易需要你在大屏上确认
- **AI 分歧检测** — 如果量化说买、AI 说卖，标记为"分歧"，不执行
- **多节点 Claw 交叉验证** — 不同节点用不同模型，判断一致性越高越可信

### 7.2 回测验证

在 AI 策略上线前，必须：
- 用历史数据回测 AI 的建议质量
- 对比"纯量化"和"量化+AI"的收益差异
- 确保 AI 不是在"事后诸葛亮"

### 7.3 成本控制

AI 调用是有成本的：
- 每天调用 LLM 几十到上百次
- 建议用本地部署的模型（Qwen-72B / DeepSeek）降低成本
- Claw 默认休眠（从属模式零 LLM 调用），只在协作/自治模式消耗算力
- 盘前/盘后用大模型深度分析，盘中用小模型快速判断
- 算力弹性调度：空闲→小模型，紧急→大模型（见 4.5 节）

### 7.4 断网/故障保护（降级自治）

```
Master 断线 → 节点自动切换自治模式（见 4.3 节）:
  - 唤醒本地 Claw AI 接管决策
  - 切换到保守策略参数
  - 默认不开新仓，收紧止损
  - 每 30 秒尝试重连
  - Master 恢复后同步记录、Claw 降回休眠

节点断线 → Master 标记该节点为离线:
  - 大屏显示 🔴
  - 不再向该节点发送指令
  - 告警通知（微信/短信）
  - 该节点的持仓风险由其他节点/Master 监控
```

### 7.5 合规与审计

每一笔交易必须记录：
- **谁下的指令**（AI 自动 / 人工手动）
- **为什么**（AI 分析理由 / 策略信号）
- **什么时候**（精确到毫秒）
- **结果如何**（盈亏、滑点）

这些日志既是复盘材料，也是未来优化 AI 的训练数据。

### 7.6 多账号策略隔离

不同账号可以跑不同风格：

| 账号 | 策略风格 | 仓位上限 | 止损线 |
|------|---------|---------|-------|
| 模拟 test1006 | 激进（验证新策略） | 100% | -5% |
| 实盘 A | 稳健（已验证策略） | 60% | -3% |
| 实盘 B | 保守（低波动） | 40% | -2% |

## 十、总结

这套系统的核心不是"用 AI 预测涨跌"，而是：

1. **Master 负责"看全局"** — 市场方向、候选池、跨账号风控
2. **Claw 负责"想"** — 每个节点自带 AI 大脑，分析个股、识别风险、判断买卖点
3. **量化负责"算"** — 精确计算技术指标、仓位、止损
4. **Bridge 负责"做"** — 通过 QMT 精确执行交易
5. **大屏负责"看"** — 实时监控所有节点、所有决策、所有风险

**关键设计：Claw+Worker 融合 + 降级自治**

- 正常时：Master 协调，Claw 休眠省算力，节点只执行
- 需要时：手动开启协作模式，Claw 做二次确认提升决策质量
- 紧急时：Master 宕机，Claw 自动接管，保守策略保护持仓
- 恢复时：Master 上线，Claw 同步记录后回到休眠

这不是一个"自动赚钱机器"，而是一个**分布式 AI 交易团队**：

每个节点都是一个有独立判断能力的 AI 交易员。
Master 是团队领导，负责战略方向。
即使领导不在，每个交易员也能独立保护自己的仓位。

最终目标：你坐在大屏前，看到的不是密密麻麻的 K 线图，而是 AI 用人话告诉你：
"今天市场偏强，建议维持仓位。600519 技术面突破+消费板块资金流入，建议买入 100 股 @1800，止损 1750，目标 1900。置信度 82%。节点 A 和节点 B 的 Claw 均确认。"

你只需要点一下"确认"，或者让它全自动执行。
