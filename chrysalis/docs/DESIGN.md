# Chrysalis 设计文档

> 化蛹系统 — 宠物进化 & PK 对战

## 1. 设计理念

### 1.1 虫族进化链

```
Larva(幼虫) ──→ Chrysalis(化蛹) ──→ Claw(成虫)
   │                │                    │
 移动端入门      蜕变/成长/战斗        完全体AI节点
```

Chrysalis 是虫族生命周期的中间态——蛹。蛹壳内发生：
- **属性重组** — 基于使用数据计算四维属性
- **形态变化** — 进化路线决定最终形态
- **基因突变** — 概率触发变异特质
- **外骨骼生长** — 装备系统

### 1.2 核心循环

```
日常使用 Claw → 经验积累 → 等级提升 → 属性增长
                                         ↓
购买装备 ← 赚取星能 ← PK 对战 ← 注册竞技场
   ↓                      ↓
 花费星能              掉落材料 → 打造装备
   ↓
伴生星尘 → 购买稀有装备/打造消耗
```

## 2. 开源策略

### 2.1 开源部分 (chrysalis/)

| 模块 | 文件 | 理由 |
|------|------|------|
| 战斗引擎 | `engine/battle.go` | 透明公平，社区审计 |
| 数据模型 | `model/*.go` | 社区扩展内容 |
| PK Handler | `handler/battle.go` | API 参考实现 |
| 扩展 Handler | `handler/extended.go` | 赛季/打造/变异 |
| SDK | `sdk/chrysalis.go` | 第三方集成 |

### 2.2 闭源部分 (保留在 Queen 侧)

| 模块 | 理由 |
|------|------|
| QueenClient 计费 | 核心收入，防绕过 |
| 星尘经济模型 | 经济平衡参数 |
| 匹配/排行后端 | 防刷榜 |
| 管理后台 | 运营工具 |

### 2.3 独立发布

## 3. 系统设计

### 3.1 四维属性

| 属性 | 基础公式 | 含义 |
|------|---------|------|
| HP | `Level × 50 + Memories × 2` | 记忆多 = 血厚 |
| ATK | `Level × 8 + Tasks × 3` | 任务多 = 攻击猛 |
| DEF | `Level × 5 + Satisfaction × 20` | 好评多 = 防御高 |
| SPD | `Level × 3 + Conversations × 0.1` | 对话多 = 速度快 |

### 3.2 进化路线

| 路线 | 图标 | 加成 | 进化链 |
|------|------|------|--------|
| 深渊 abyss | 🌊 | HP+20% DEF+15% | 小龙虾→蛟→深渊蛟龙 |
| 地表 terrain | 🏔️ | ATK+20% SPD+10% | 小龙虾→刺蛇→猛犸虾王 |
| 天空 sky | 🌪️ | SPD+25% ATK+10% | 小龙虾→飞虾→风暴翼龙 |

### 3.3 装备品质

| 品质 | 颜色 | 货币 | 获取 |
|------|------|------|------|
| 白色 | ⬜ | 星能 | 商店 |
| 绿色 | 🟩 | 星能 | 商店 |
| 蓝色 | 🟦 | 星能 | 商店 |
| 紫色 | 🟪 | 星尘 | 商店/打造 |
| 橙色 | 🟧 | — | 打造/掉落 |

### 3.4 赛季环境 Buff

每个赛季有一个 `environment` 属性 (abyss/terrain/sky)。
匹配该路线的战斗员获得额外属性加成 (`ATKBonus`, `DEFBonus`, `SPDBonus`)。

### 3.5 战斗掉落

| 材料 | 掉落率 (胜/败) | 描述 |
|------|----------------|------|
| 甲壳碎片 | 100% / 100% | 基础材料 |
| 锋利钳爪 | 100% / 100% | 基础材料 |
| 深海水晶 | 40% / 15% | 进阶材料 |
| 风暴羽翼 | 40% / 15% | 进阶材料 |
| 大地之石 | 40% / 15% | 进阶材料 |
| 进化精华 | 10% / 0% | 稀有材料 (仅胜者) |

### 3.6 变异系统

进化时有概率触发变异，获得永久特质：
- **普通 60%**: 铁壁(DEF+8%), 迅捷(SPD+8%), 狂暴(ATK+10%,-5%DEF), ...
- **稀有 30%**: 嗜血(击杀回血15%), 闪避大师(15%闪避), ...
- **传说 10%**: 不死鸟(复活30%HP), 虚空行者(20%无敌), 毁灭之力(ATK+25%)
