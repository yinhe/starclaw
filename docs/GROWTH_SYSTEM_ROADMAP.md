# 龙虾成长经济系统 — 开发路线图

> 从设计到上线的完整实施计划

## 总览

```
Phase 0: 基础重构（1 周）     ← 改造现有代码适配新设计
Phase 1: 虫群系统（2 周）     ← Agent 自动变虫 + 虫群展示
Phase 2: 地球进化路线（2 周） ← 72 种形态 + 进化动画
Phase 3: 星尘经济（2 周）     ← 获取/分配/商店
Phase 4: PK 2.0（3 周）       ← 虫群对战 + 吸收/惩罚
Phase 5: 境界系统（2 周）     ← 仙魔妖三道 + 光环
Phase 6: 终局内容（2 周）     ← 觉醒/融合/转生
Phase 7: 赛季 + 社交（持续）  ← 每月赛季 + 排行榜 + 观战

总计：约 14 周（3.5 个月）到完整上线
```

## 风险与应对

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 美术资源不足（72 种形态） | 高 | 上线延迟 | Phase 2 先用 emoji，后续替换精美图 |
| PK 数值不平衡 | 中 | 玩家投诉 | 内测期收集数据，快速调参 |
| 星尘通胀（获取太容易） | 中 | 经济崩溃 | 设置每日上限 + 定期审视 |
| 退化惩罚太重导致玩家流失 | 低 | DAU 下降 | 保护机制 + A/B 测试惩罚力度 |
| 仙魔妖选择后悔 | 低 | 差评 | 提供一次免费"洗道"机会 |

## 优先级排序

如果资源有限，按以下顺序裁剪：

```
必做（MVP）:
  Phase 0 + Phase 1 + Phase 2（部分）
  → 虫群 + 地球进化 → 已经很有趣

应做:
  Phase 3 + Phase 4
  → 星尘经济 + PK 2.0 → 有竞争 = 有粘性

可做:
  Phase 5 + Phase 6
  → 仙魔妖 + 终局 → 深度内容

持续:
  Phase 7
  → 赛季 + 社交 → 长期运营
```

**MVP 只需 5 周就能上线一个让用户"哇"的版本。**
