### 2. [图N] 标签系统（角色一致性的命门）

每个角色锁定一个 [图N] 标签：
- [图1] = 林见月 | [图2] = ZERG | [图3] = 苏蜜 | [图4] = 温婉 | [图5] = 颜术

**Prompt 前缀（全集一字不差复用）**：
```
[图N]角色名：外观完整描述（服装+发型+体型+配色）
严格按参考图还原角色外观，绝不改变服装/发型/体型/配色。
```

**EP03 经验**：v2 采用 [图N] 标签后，六镜全部一次通过角色一致性。这是最大的降本手段。

### 3. 角色 Appearance Card 设计

每个角色必须有一张固定的外观卡，**全集全季一字不差复用**：

```
[图1]林见月：
  薄荷绿古装汉服+透纱外袍的瘦弱年轻中国女子，
  黑色长直发柔顺，古风流苏耳环+翡翠银腰扣，
  皮肤白皙干净，赤脚（室内）。
```

**规则**：
- 服装/发型/体型/配色必须在一句话内写清
- 不写抽象词（"美丽""优雅"）— 要具体可拍
- "24岁/韩系甜美/酒红深V" 这种具体描述比 "漂亮" 有用10倍
- 写完后放进 `bible.md` 的 characters 段

### 4. 情感弧线设计

每集必须有明确情感弧线（6场为例）：

```
EP04《新世界》情感弧线：
S1: 好奇+陌生（林见月第一次在现代房间醒来）
S2: 爆笑（手机当镜子）
S3: 惊吓→搞笑（吹风机=法器？）
S4: 欢乐+嫌弃（ZERG被穿衣服拍抖音）
S5: 崩溃+好奇（苏蜜炒股亏了/林第一次看K线）
S6: 温暖+暗示（古铜钱发暖/ZERG感知数据异常/伏笔）
```

规则：
- 不能平铺直叙，必须有情绪起伏
- 结尾留悬念/暗示/伏笔，不要CTA式收尾
- 前1秒给压力，前3秒给异变，前8秒给不可逆动作

### 5. 伏笔体系（跨集暗线）

伏笔设计原则：
- 每个伏笔有**埋入时机**和**回收时机**
- 伏笔类型：
  - **物件型**：古铜钱（发暖）、翡翠银腰扣、半块饼
  - **行为型**：ZERG感知数据异常、林见月看K线能看懂
  - **感知型**：心跳同步、熟悉感、共鸣
  - **旁观者型**：苏蜜的无意识点评
- 伏笔清单表：伏笔名 | 埋入集 | 回收集 | 作用

### 6. 跨集连续性检查

新集开头必须与上一集结尾衔接：
- 人物状态（服装/位置/情绪）
- 场景延续（时间跳多久、地点变化）
- 伏笔推进（上集埋的本集能不能推进？）

自动比对上一集 EP0x.md 结尾和本集开头，输出不一致报告。
