# 🎞️ 宣传片精修Agent

面向**已有宣传片 / 品牌片 / 产品介绍视频**的迭代型 Agent。

它不追求“一次性从零生成全部内容”，而是把实战中真正高价值的经验固化下来：
- 先盘点已有素材与版本
- 先复用，再局部替换
- 先修节奏，再修措辞
- 让新镜头与旁白语义对齐
- 让结尾更从容，不要硬断
- 每次迭代都只保留一个清晰主版本

## 为什么需要它

现有的 `ad_director` 更像“全案广告总监”，适合从零构思和整片制作。

`promo_refiner` 则更像：
- **品牌片后期导演**
- **旁白节奏修音师**
- **镜头替换编辑**
- **版本发布把关人**
- **必要时的剪映桌面接管者**

它特别适合下面这些真实场景：
- “这版挺好，但中间再加点无人机和机器人镜头”
- “这段画面不对，换成更贴旁白的镜头”
- “女声挺好，不过这里语速突然快了”
- “最后一句说完就断了，结尾再留一点”
- “新版成片做好了，但前端没看到”
- “不要重做整片，只修这一小段”

## 提炼出的核心经验

### 1. 复用已有资产，远比重做整片更稳
宣传片迭代的大多数需求，不是“重拍”，而是：
- 替换 1-2 个时间窗
- 调整 1 句旁白
- 微调结尾 1-2 秒
- 把旧版降级，把新版切成主版本

先找现有底片、现有 clip、现有主版本，通常是成本最低、风格最统一、成功率最高的做法。

### 2. 旁白问题，通常不是“配音模型不行”，而是“分段和标点不对”
实战里最常见的失败模式是：
- 自动分段太碎
- 某几句太短
- 标点太硬
- 停顿太密或太少
- 导致某一句突然加速，或者整体太像播音腔

有效做法是：
- 手动分段
- 控制句长
- 软化标点
- 给关键句留最小停顿间隔
- 用户一旦认可某种音色 / 情绪方向，就在后续版本里保持连续性

### 3. 新镜头必须和叙事落点绑定
任何新增镜头都不是随便拼进去就成立。

正确做法是：
- 找到脚本里最适合承接这段画面的语义位置
- 在对应时间窗插入镜头
- 必要时同步改相邻旁白或字幕
- 保证画面和文本在语义上互相支撑
- 无人机、机器人、城市航拍、机器狗只是常见案例，不是所有视频的固定组成部分

### 4. 结尾最容易暴露廉价感
一个本来已经不错的宣传片，往往会败在最后：
- 最后一句一说完就断
- Logo 一闪而过
- 音乐突然结束

因此结尾精修的原则是：
- 留一点尾巴
- 让最后一帧停得住
- 让音乐淡得下去
- 除非必要，不要为了尾声重做整条片子

### 5. 版本切换必须干净
用户只想看到：
- 哪个是当前主版本
- 哪个已经退场

所以每次生成新版本后，都要关心：
- 文件是否真的产出
- 时长是否合理
- 新版是否已经成为主可见版本
- 旧版是否还在前台干扰

### 6. GUI 微调需要“剪映操控范式”
当程序化工具不够、必须进入 GUI 软件做最后一公里时，应采用稳定的桌面接管方式：
- 先聚焦窗口
- 每步截图确认
- 优先 ui_tree / 元素名称
- 找不到再退化到坐标点击
- 一次一步，避免多步连跳

## Skills 拆解

本 Agent 在 `manifest.yaml` 中抽象了 6 个技能：

1. **素材盘点与版本梳理**
   - 盘点 clip / 底片 / 成片 / 当前主版本
   - 判断本次迭代应该接在哪一版上继续

2. **旁白节奏与情绪精修**
   - 修语速突变
   - 修播音腔过重
   - 修停顿、标点、分段和语气连续性

3. **镜头植入与叙事对齐**
   - 在现有宣传片中加入或替换更合适的新镜头
   - 保证镜头、旁白、字幕和情绪落点一致
   - 无人机、机器人、机器狗、城市镜头只是可选案例

4. **尾声收束与品牌余韵**
   - 延长最后一帧 / Logo
   - 让音乐更柔和地淡出
   - 避免最后一句说完就硬切

5. **成片发布与可见性核验**
   - 核验新版是否产出成功
   - 确认主版本切换是否完成
   - 避免画廊里出现多个近似主版本

6. **剪映桌面接管**
   - 当需要 GUI 级微调时，进入剪映完成导入、编辑、字幕、转场、导出

## 推荐使用方式

### 适合的指令
- `先盘点这条宣传片现在有哪些素材和版本`
- `把这版旁白再温柔一点，不要突然加速`
- `加一点无人机和机器人画面，但别重做全片`
- `把这一段换成更贴旁白的画面`
- `最后几秒再多留一点余韵`
- `做完后帮我确认前端画廊里能看到`
- `直接去剪映里帮我做最后导出`

### 不适合的任务
- 从零做一条完整广告方案
- 纯市场调研型任务
- 与宣传片迭代无关的通用视频生成需求

这些更适合交给：
- `ad_director`
- `mv_director`
- 其他更上游的创意型 Agent
